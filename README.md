## 已经留下的关键认识

- 整体MAG/PHA接近时，局部结构仍可能明显不同；部分结构更好的候选甚至被整体双目标支配，不能把原因全部归于最终选解。
- T、C、B和ARX在特定开发条件有改善，但后续批次、窗口外副作用及计算成本限制了结论。
- 辅助分数数值可靠、与MSE相关、能够修复个别反例，都不自动证明加入优化有效。
- 有序复路径、频率位置和频率展开宽度不能互相代替。最新G/P是有解释依据的候选分量，尚未完成一般形变归属或优化验证。

## 材料组织

`docs/` 保存方案与研究说明；`experiments/` 保存科学实现、配置、输入及选定历史统计；`output/` 保存报告、逐seed/事件表、图与核验；`references/` 保存工作区已有的论文与辅助指标公式PDF；`scripts/` 保存相关分析与报告脚本。

本仓库是研究阅读与代码归档，**不是全部历史运行数据的镜像**。原始优化压缩包、部分完整种群、服务器运维文件和依赖环境保留在本地。引用但未归档的文件可在[本地材料索引](archive/LOCAL_ONLY.md)查到。具体复算条件见[复算与核验说明](archive/REPRODUCIBILITY.md)。

数值和原协议保持原样；阅读副本中的本机Markdown链接改为相对链接。原文件与导出副本分别有SHA-256记录。历史报告中的“未上传网站”“未启动优化”等表述指当时那轮工作，此次仅归档。
