# Case2 最终方法：分层指标体系与核心优化组合

## 最终决策

最终方法不是“只保留两个指标”，而是采用分层指标体系：

|层级|指标|角色|
|---|---|---|
|主拟合指标|幅值 MSE、相位 MSE|衡量整体数值拟合质量，参与进化|
|核心结构指标|I-03 电抗过零方向一致性、II-02 转变速度相对误差|提供结构引导，参与进化|
|独立诊断指标|II-01 特征频移、P-03 DTW、P-05 最大局部幅值误差|用于报告、验收和失效诊断，不增加 Pareto 维数|

因此，NSGA-II 实际优化四个目标：

\[
\min_{\theta}\left[
L_{\mathrm{mag}},
L_{\mathrm{phase}},
L_{\mathrm{I03}},
L_{\mathrm{II02}}
\right].
\]

## Motivation

幅值和相位 MSE 将阻抗曲线视作逐频点误差的集合，不能显式区分电抗过零方向错误、特征转变过快或过慢等结构性失配。另一方面，把大量特征全部作为独立 Pareto 目标会扩大非支配解集合、削弱选择压力，并使冗余或冲突指标干扰主目标。因此需要一组数量尽可能少、信息互补且能在独立随机种子上稳定改善主误差的核心指标，同时保留更完整的诊断指标体系。

I-03 描述过零事件的方向和定性结构；II-02 描述沿对数频率轴的局部变化速度。二者分别提供离散事件信息与连续动态信息，形成互补，而不是重复衡量同一种误差。

## Idea

1. 参数在 log10 空间编码，以 NSGA-II 同时优化两个主误差和两个核心结构损失。
2. 四个目标共同决定进化过程，不在进化前进行主观加权合并。
3. 进化完成后，从最终种群选择 `magnitude MSE + 17.38 × phase MSE` 最小的同一个体。该 WSMSE 只用于最终选解，不参与进化。
4. 对最终解另外计算 II-01、P-03 和 P-05，用于识别特征错位、全局形状错配和局部最坏误差；这些指标不再作为额外 Pareto 目标。

固定协议为：种群 150、300 代、SBX 交叉、PM 变异、同 seed 各组共享完全相同的初始种群。

## 独立证据

|阶段|Seeds|幅值变化|相位变化|
|---|---:|---:|---:|
|完整两两筛选|0–99|-42.669%|-14.381%|
|第一次独立验证|100–199|-40.529%|-13.823%|
|冠军复赛|200–399|-38.374%|-12.480%|

冠军复赛包含 11 组、2200 次正式优化和 9900 万次个体评价，失败 0 次。严格多重比较校正后，I-03+II-02 的幅值和相位改善仍同时成立。其 WSMSE 从 7.83942 降至 5.22249，降低 33.382%。

## 为什么不继续增加目标

|方案|幅值变化|相位变化|
|---|---:|---:|
|I-03+II-02|-38.374%|-12.480%|
|I-03+II-01+II-02|-35.061%|-9.615%|
|I-03+II-02+P-03|-33.939%|-9.801%|

增加 II-01 或 P-03 后，两项描述性均值都变差，且相对 I-03+II-02 没有直接配对统计优势。因此，II-01 和 P-03 适合作为诊断指标，但没有证据支持将其继续作为独立进化目标。

## 参数稳定性与解释边界

I-03+II-02 将参数 log10-IQR 中位数从 1.1196 降至 0.9328，将参数边界附近命中率从 3.87% 降至 1.33%。这说明跨 seed 结果更集中，但 Case2 没有真实元件参数，因此不能将其解释为参数恢复精度提高。

后续 1200 次鲁棒性优化表明，该组合在 0.1 dB/0.5° 噪声、0.3 dB/1.0° 噪声以及频点减半至 101 点时仍通过严格双指标校正。0.5 dB/2.0° 噪声下相位证据变弱；仅保留 51 点时收益不再显著；随机连续缺失 20% 频段时相位均值恶化 2.005%。因此，当前结论支持“在完整频段得到充分采样时，I-03+II-02 是最简且稳健的核心辅助组合”。更多实测案例的泛化仍需单独验证。

实际应用应先检查频率覆盖：建议至少保留约一半的原始频点并覆盖完整频段。若关键频段连续缺失，不应依赖事件和导数型指标补偿缺测数据，而应补测、插值后单独验证，或退回双主目标基线。

对全部十个入围组合的后续比较与新 seeds 500–599 独立验证进一步给出条件化策略：默认完整覆盖或频点减半时继续采用 I-03+II-02；若已知噪声达到约 0.5 dB/2°，P-03+P-05 是经过独立验证的备选（幅值 -36.166%、相位 -11.949%、WSMSE -31.746%）。若仅剩四分之一频点或连续缺失关键频段，则没有任何候选获得可靠证据，应补测或退回基线，而不是根据同一批数据临时更换指标。
