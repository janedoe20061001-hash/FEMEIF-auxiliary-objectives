# 采样可行性诊断：2026-10-08

本实验只复评已有曲线，不重新优化，不新增辅助损失。目标是区分“理论模型可主动查询”和“离线实测数据不能主动补值”，并检查自适应频点是否确实表达曲线。

## 冻结样本

Case1解析目标一条；已有双目标100个seed（2300–2399）的300代主图选解与均衡选解，各100条。采用已有selected_index和balanced_index，不按新诊断重新选解。两种规则可能选到同一个体，不视为200次独立优化。

## 四种表达网格

1. 原始180点。
2. 上轮仅根据目标准备的固定731点。
3. 每条曲线从原始180点开始，检查相邻点的log f中点；若中点的dB幅值/角度相位偏离端点插值超过0.1dB/0.5°，继续细分该区间。所有查询点保留。最大3000点、24层；预算不足按区间顺序等间隔选取待查区间，不按最终结果排序。报告预算/深度停止标记。中点检验通过不构成任意连续曲线的保证。
4. 已有模型结构与参数引导的模态网格，使用improved_dense_grid refinement=1。该方法点数不固定，不宣称与前述方法有相同计算预算。

第三种不查看真参数或谐振位置，只查询曲线值。第四种利用本来已知的模型参数定位结构；对解析目标可以使用生成目标的参数，对真实目标则不可冒充已知真参数。第四种是计算模型诊断工具，不是实测仪器通用采样方案。

## 独立复评

每条曲线在参数引导的refinement=2与4两档网格复评：比较采样点连线与真实模型响应的最大dB幅值差及最大相位角度差。两档都满足≤0.2dB、≤1°才记为通过；单独报告两档差值与稳定性（最大差值变化≤0.02dB/0.1°）。不稳定者不支持精确优势结论，不删除。该复评仍依赖已知Case1模型，不能证明所有未知曲线都不漏峰。

本实验衡量“检查/连线是否看清楚”，不衡量优化效果。未更改评分权重，也未运行新的搜索；新增点不自动等权加入损失。后续训练比较必须保持频率积分口径并单独报告计算成本。
