## 数据与电路

`data/targetImpedance_case2.csv` 是用户原文件的逐字节副本。按用户选择使用全部201点（40 Hz–110 MHz），不平滑、不插值、不裁剪。`mag`按欧姆、`pha`按度读取；主目标使用幅值dB与相位弧度的均方误差。CSV校验值、实际频率和复阻抗均写入manifest。

论文Table V使用96点，图示拟合频段更窄。本批保留用户提供的全频段，故不可直接把误差数值与论文表中的误差作同条件比较。

电路为英文论文Fig.15：三个串接的子网络，每个子网络由电容、串联的电感与奇数号电阻、偶数号电阻三条支路并联；最后再串接C4、R7、L4。共15个参数，顺序为R1–R7、L1–L4、C1–C4。电阻边界0.01–10^4.5欧姆，电感10^-9–10^-4 H，电容10^-12–10^-7 F。没有真实参数注入或Case1合成目标回退。

两个主目标及报告选解规则为：

\[
E_A=\frac1N\sum_k(20\log_{10}|Z_k|-20\log_{10}|Z_k^*|)^2,\quad
E_\phi=\frac1N\sum_k(\arg Z_k-\arg Z_k^*)^2,\quad
S=E_A+17.38E_\phi.

## 辅助指标迁移的已知情况

沿用Case1中文PDF18指标实现中的公式与常数；不根据Case2结果调参。原有转折检测在本数据中检出2个转折，都在低频端；电抗过零9次，幅值峰谷11个。检测结果不是对真实电路物理事件数量的认定，可能受测量噪声及全频段归一化影响。

原实现将所需事件数按目标检测数封顶，因此I-01与I-05在这里等价，I-02与II-11也等价。保留19组计划便于与Case1按标签对照，但不能把上述等价组作为独立有效指标重复计数。正式结果报告会提示这一点。准备阶段256个随机参数样本仅检查指标数值与变化范围，不是拟合实验，也不能据此判断有效性。详见`prepared/data_audit.json`。

## 服务器正式运行入口

Linux服务器创建环境并安装锁定依赖后，在本目录执行：

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python test_case2.py
bash run_server.sh --run
```

`run_server.sh`要求显式`--run`，不带参数不会启动。默认28个worker，可用`WORKERS`环境变量调整。它在前台执行完整批次，再生成报告；长任务可在tmux中运行。不要同时启动两个协调进程。

每次运行保存初始种群、每代历史、最终全种群和完成标记。协调器写入`runs/progress.json`。再次运行只跳过配置、代码和数据指纹匹配且文件齐全的已完成记录；发现未完成目录时停止，避免悄悄覆盖。

完成后生成`RESULTS.md`、`STABILITY.md`、逐seed选解与配对汇总，以及原始结果压缩包和SHA256。报告重新计算最终种群的两项主目标并核验选解；统计包含配对bootstrap区间、18组×两项的36项比较调整以及少数seed影响检查。置信区间使用近似bootstrap覆盖率；指标筛选结果仍需后续独立验证。
