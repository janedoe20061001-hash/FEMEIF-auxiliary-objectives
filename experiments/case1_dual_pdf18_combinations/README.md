# Case I：三个候选辅助目标的组合实验

新增三组两两组合和一组三指标组合，每组 seed 0–99，200 个体、300 代。

- A：电抗过零方向一致性（I-03）
- B：局部特征频移误差（II-01）
- C：转变速度相对误差（II-02）

运行 A+B、A+C、B+C、A+B+C；复用上一批 baseline、A、B、C 共 400 次完整原始结果，来源保持独立，原始 fingerprint 不改写。报告核对配置（组别除外）、频率、指标定义、选解规则、依赖版本及相同 seed 的初始种群哈希。

算法保持 NSGA-II，两个主目标与全部选中辅助目标均参与交配和环境选择。每个 seed 仅从最后一代选择幅值 MSE + 25.12 × 相位 MSE 最小的一个个体，两项误差取自同一个体，跨 100 seed 求均值。辅助指标分别占据一个目标维度，不相加合并。

沿用此前 180 点对数均匀频率网格。中文 PDF 原 401 点频率坐标缺失，本实验不声称精确复现该采样。

主比较是四组组合是否分别使两项均值低于 baseline；报告另列组合相对组成它的单指标、两指标组合的变化。均值结果不等同于统计显著性。

服务器使用 launch_batch.py 运行四组，随后 report_results.py 审计新运行和 reference 中的历史运行，输出报告、所选个体、三种统计口径、组成项比较和包含两批来源的原始归档。实际状态见 server_run/progress.json 快照。
