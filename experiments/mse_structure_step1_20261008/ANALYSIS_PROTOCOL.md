# 第一步结构分类口径（读取新训练结果前固定）

目标事件ID由Case1目标的模态加密网格固定；幅值突出度1dB，峰P1–P6、谷V1–V5按各自频率排序。采用同类一对一匹配，位置窗口0.25 decade。

“存在对应事件”只表示匹配到，不等于形状恢复。较完整恢复的诊断要求：位移≤0.02 decade（约4.7%频率差）、高度差≤3dB、局部3dB宽度比在[0.5,2]内。三个阈值是事先约定的筛查条件，不是物理真理或新增优化目标；连续误差同时保留。

局部3dB宽度：峰下降3dB、谷上升3dB处的log f跨度。它不同于此前“半突出度宽度”，不能混用两种宽度数值。突出度不足3dB的拟合事件不能提供这一宽度，不当作零偏差。使用该口径是为区分真实极窄核心与长尾/背景带来的宽度。

相位按log f等宽8个频带比较RMSE；>15°记为局部偏差，连续RMSE同时报告。该标签不单独证明物理相位转变数量错误。典型图用固定seed2307/2312/2321、目标25.23kHz附近与100–316kHz局部曲线。

每20代诊断两种代表规则。300/1000代两组全部非支配解逐一诊断；前沿能否恢复按每个事件、每个频带分别报告，不能把不同个体各自恢复的部分拼成一条完美曲线。另报告是否存在同时恢复全部幅值事件/全部相位频带的单个前沿解，以及其幅相代价。

前沿事件可恢复性还报告对应解的共同网格幅相误差，与代表解比较取舍；事后结构较优解仅用于诊断，不替代主图成绩。分类表保留基础训练分数与共同解析网格误差，不能混合两种评分口径。

两档网格检查共同RMSE、事件漏失、较完整恢复计数，必要时继续4/8档；不稳定保留标记。配对95%区间按100个seed重采样10000次，RNG2026100802；条件于Case1、算法和预算，未作多重比较校正。
