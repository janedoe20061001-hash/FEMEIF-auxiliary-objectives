# 第一步：确认MAG/PHA困难结构

2026-10-08。只研究Case1理论目标，当前不新增辅助指标、不扩充实测训练、不发布网站。

四个主线问题固定：哪类结构反复难以恢复；什么条件使其更难；针对性指标能否改善；改善能否推广且代价是什么。本轮只确认第一个问题，并准备第二个问题的候选。

## 训练对照

100个配对seed：2300–2399。电路、真目标、边界、种群200、算子和初始种群与已有双目标实验一致。每个seed跑原180点与可靠自适应两组，各1000代；保存300代和1000代完整种群及前沿，每20代保存两种代表解。300代原组必须与原实验逐项一致，确认延长终止代数未改变前300代路径。

只有MAG/PHA两个训练目标。原组完全使用冻结原程序等权MSE。自适应组采用原log频率单元总权重1/180、单元内积分，保留原频段权重；区别包括数值积分和候选检查，不宣称与原有限点MSE数学上完全同一目标。基于已有731点目标网格与候选已知RLC支路中心加密，再用幅值0.1dB/相位0.5°中点偏差细分；最多10000点、32层。超过限制使运行失败并保留记录，不静默罚分、不增加结构目标。

每个目标都有参数范围内的零误差解。本轮只能研究固定算法预算下的困难，不能证明MSE全局最优仍错误。

1000代各组的300代阶段构成短预算对照，不额外重新优化。主图选解取当前非支配前沿MAG+25.12PHA最小值；敏感性取min max(MAG,25.12PHA)。α仅选解。保留完整前沿检查“好结构解是否已经存在而未被选中”；结构最优解仅用于存在性诊断，不冒充原选解成绩。

## 开跑前必要检查

目标自身零误差；单/批评价一致；同seed初始化逐项一致；两种电路实现对原点响应一致；原单元质量不变。自适应损失在原有末代代表、边界例子和固定随机参数上与两档模态加密积分比较。幅值绝对误差≤max(0.01dB²,0.005×参考MSE)，相位≤max((0.5°)²换算为rad²,0.005×参考MSE)；未通过者保留并修复数值方法，不宣称可靠采样基线完成。计算耗时与频率查询次数单独报告，同候选次数不等于同计算成本。

## 结构诊断

主阈值：幅值峰谷突出度1dB，相位事件5°；幅值0.5dB与2dB阈值作敏感性。原方法按同类事件0.25 decade匹配。分类：事件漏失，匹配位置偏移，宽度偏差，局部相位转变偏差。峰谷特征是曲线事件，不等于电路模态数量。

固定Case1目标事件ID与邻近频带；宽度只统计匹配事件，漏失不计零偏差。用理论模态与加密网格同时诊断目标/候选。两档网格检查幅相RMSE和事件数；不稳定者继续加密，仍不稳定者标记，不支持精确优势结论。

统计每个目标事件在哪些seed、阶段漏失，及其位置/宽度残差；每20代追踪主图和均衡规则，区分总误差改善与局部结构恢复。前沿诊断覆盖300/1000代两组全部非支配解，报告有恢复该事件的解的seed数，以及这些解与代表解的幅相取舍。事后挑图不改变统计/选解。

配对比较：自适应300−原300，自适应1000−原1000，两组各1000−300。按seed重采样10000次，RNG=2026100802，报告95%区间，不作所有电路的总体推断。延长预算仍困难只提供有限预算证据；不能排除算法搜索困难。
