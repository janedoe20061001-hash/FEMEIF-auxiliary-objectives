# 大样本电路参数—阻抗响应研究

扩展第一轮的少量机制示例，保留其结果不改写。本轮新增16种连接模板，每种144组参数，共2304个基准电路；两批独立固定种子样本各72组/模板。

覆盖：RC/RL串并联、RLC串并联、二/三谐振单元串联或并联、RC/RL双过程、RC及RLC梯形网络、带串联RLC背景的谐振网络、RLC桥式网络。模板不同不等于端口函数必定互不等价。

每批按3个名义阻尼档×3个频率间距档×8组Latin hypercube参数样本覆盖。对于独立串/并联RLC，阻尼档对应Q（0.5–2、2–20、20–200）；对耦合网络只是元件构造控制，不冒充实际端口Q。非谐振RC/RL不解释Q，取同频率/阻抗范围的144组独立参数配置。

- 内部频率锚点起点1k–100k Hz；相邻锚点比例1.05–1.4、1.5–4、6–30；阻抗基准10–1000Ω，各过程另有阻抗比例变化。
- 观察频带100Hz–100MHz。采用精确网络极点/零点引导每条谱的局部加密，以等log频率积分统计；不把加密点当成更多独立样本。
- 单参数及整体阻抗缩放、整体频移、首个LC互补方向，均取0.1/0.3/1/3/10/30档正向与倒数负向；不裁剪元件值。
- 事先定义待检查的经验命题：R增大是否各频点幅值不降、R增大是否各频点相位绝对值不增、C增大是否相位不升、L增大是否相位不降、参数误差增大时幅相RMS是否单调、频带内峰数是否保持。按每个基准电路聚合后统计，避免把同一电路的多个参数/频点重复算成独立电路。
- 两种RLC精确缩放恒等式作为解析规律验证。其余经验命题按模板、参数档和独立批次报告支持比例与反例，不宣称“样本多即可证明普遍性”。
- 旧指标审查在统一513点等log网格进行，复用I-03/II-01/II-02及累计弧长的原公式；无目标过零时I-03记未定义，不能记零。本轮网格与Case1/Case2正式网格不同，不直接比较历史成绩。
- 按预定子集做加密收敛检查；挑选的反例另作加密确认与科学绘图。密集曲线只代表理想被动集总元件模型，不覆盖有源电路、分布参数或电化学CPE/扩散元件。

本地运行，无优化器、无服务器。脚本支持先导运行 `--pilot`（每模板一组）和完整运行；`--plot-id` 可从任意已保存的基准参数生成指定参数的曲线，无需重跑整批。

## 图册与结构图

新版图册按“电路与曲线 / 规律总结 / 反例 / 数据与方法”导航。每个电路先显示标准元件结构图与带单位的参数表，参数表采用与当前曲线一致的基准编号；扰动倍率选择只更新表格，曲线仍同时展示所有倍率。覆盖图叠加九组样本，并可逐组查参数。反例另用其自身的完整基准参数。

`schematics/*.svg` 是可下载的电路结构图；各模板参数导出为 `data/*_parameters.csv`。网站和这些CSV的构造档、间距档使用1起始索引，原始JSON的bin字段使用0起始索引。原始元件值保持SI单位，网页换算为Ω/kΩ、H/mH/µH、F/µF/nF/pF等方便阅读的单位。

修改图册后运行 `rebuild_gallery.py` 即可从已有数据重建，无需重跑扰动计算。完整新实验运行 `run_population.py` 后，再运行 `analyze_conditions.py` 补全条件统计。结构图和曲线参数对应关系由 `verify_gallery.py` 检查；原实验复核入口仍为 `verify_population.py`。
