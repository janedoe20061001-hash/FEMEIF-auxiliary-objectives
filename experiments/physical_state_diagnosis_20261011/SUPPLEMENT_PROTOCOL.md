# 第一轮诊断后的补充约定

本补充在原105条干预和252条代表诊断完成后制定，不属于预先提出的第一轮假设。原文件、结果和哈希保持不变。

发现：原有过零特征的粗诊断不能覆盖许多相位事件失败；简单RLC的修订轮seed 42002阻性水平约为目标2.737倍，但过零位置和角度陡峭程度接近目标。

补充检查两项：

1. 七个理论目标各做五个整体阻抗尺度变换，共35条：每个R、L乘s，每个C除s，s固定为0.25、0.5、1、2、4。理论上所有原RLC串并联树均满足Z_s(f)=sZ(f)。在固定的目标加密网格和独立节点响应上检查：实部虚部同时变为s倍，角度保持，幅值dB偏差恒为20log10(s)。这不是拟合优化，也不把任何候选免费缩放后纳入原评价。
2. 对同样252条代表及五个目标，在原4、8级参考网格上找相位曲线的峰谷，突出程度至少5°，并用解析相位导数求零点精化。相比原导数尖峰事件，先过滤角度变化很小的起伏；不改原相位事件成功标记。

相位峰谷对应端口容性或感性占优程度的局部极值。记录φ与η=sinφ=X/|Z|，它是正弦稳态下Q/|S|的端口比例，不是内部储能之比，也不是新独立数据。只作结构解释和诊断。

目标相位峰谷以邻事件频率中点划分固定区域；候选同类峰或谷、同正负相位在区间内取频率最近者，缺失单列，剩余事件单列。位置>0.02 decade、角度差>5°作新的说明性标签，不作为原实验合格标准。两级事件类型、数量相同，频率差≤1e-8 decade，角度差≤0.001°；失败保留。

所有比较仍按原seed和膝点代表进行。两项补充属于对已见结果的解释性探索，尚非独立验证；没有新优化、组合目标或网站发布。
