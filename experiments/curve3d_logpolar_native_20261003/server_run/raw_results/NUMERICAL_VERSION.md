# 数值实现版本：不改变指标公式

最初 NumPy 版本因大量临时数组导致全点对方向差计算缓慢。只根据计算性能停止该版本，停止时 Case I 已完成 302 次；所有原始文件继续保留在服务器的 `femeif_curve3d_logpolar_20261003`，该目录的 `INTERRUPTED.json` 记录中止范围与原因。其未完成批次不用于指标比较。

本目录 `native_v2` 从头完成全部 1,400 次正式运行，不混入慢版本的中途结果。`orientation_native.c` 直接计算同一个单位向量平方差，所有原始点对保留。禁用 fast-math 与乘加融合，返回原布局的逐点对加权项，再由 NumPy 按原方式求和。

正式启动前，`test_native_equivalence.py` 对两个 Case 的完整初始种群分别检查：编译实现与原 NumPy 公式须逐位相同。这是软件计算检查，不是拟合预实验，也没有根据部分实验效果调整指标。

源码、编译参数、编译器版本、二进制 hash 和对照检查结果均归档。下载后仍以不调用编译后端的独立公式实现复算全部最终种群。
