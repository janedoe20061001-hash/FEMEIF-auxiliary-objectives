# 三维对数幅值—相位坐标：第二轮正式实验结果

两个 Case 各 7 组、每组 100 个配对随机种子；共 1,400 次运行、73,500,000 次评估，全部完成并通过审计。
Case I：种群 200、300 代；Case II：种群 150、300 代。两个 Case 均在本次同一环境中重跑基线。
主表为最后一代按既有固定 WSMSE 选出的同一个体；先取各 seed 的两项误差，再跨 100 seeds 等权平均。

## 均值、配对区间与显著性

以下 95% 区间由 10,000 次配对 seed 重采样获得，统计对象为均值比例下降，不是逐 seed 百分比的平均。
同时给出配对双侧 Wilcoxon 检验，并对 2 Cases × 6 辅助指标 × 2 主目标共 24 项比较做 Holm 修正；区间本身未做同时覆盖校正。
这些统计反映随机优化运行的差异，不包括测量噪声与换数据集带来的不确定性。

### case1 / D-01-LP 全频率对距离

- 幅值 MSE (dB²)：基线均值 13.449453，辅助组均值 13.077575；下降 2.765%，配对 95% 区间 [-11.147%, 15.436%]；Holm 修正 p=1。
- 相位 MSE (rad²)：基线均值 0.1538771，辅助组均值 0.13157978；下降 14.490%，配对 95% 区间 [-2.316%, 28.495%]；Holm 修正 p=1。
- 原双主目标前沿：辅助组严格支配的基线前沿点比例均值为 49.33%；反方向为 35.13%。此比例是补充描述，受前沿采样密度影响，不等于统一超体积增益。

## 解释范围

五个既有几何方向改用对数幅值—相位坐标，另加全频率对方向差。所有组保留双主目标并仅添加一个辅助目标；单辅助结果不能推断组合效果。
仅在一个 Case 降低两项误差不代表跨 Case 稳健；不能只依据 WSMSE 或辅助指标自身变小宣称成功。
未进行事后阈值、积分窗口或权重调优；本轮在看到第一轮负结果后提出，定义在本轮启动前冻结，但不属于独立数据验证。候选定义、取样、算子和预算在启动前冻结。

完整定义见 README.md；代码/配置来源见各 Case 的 SOURCE.json；审计见 audit.json；每代历史和最终完整种群见 runs/。
