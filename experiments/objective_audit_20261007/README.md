# 单目标结果独立核查

运行 `audit.py`，再运行 `explain.py`。前者从冻结输入和原始服务端末代种群独立重算全部2,320次运行的300,400个个体；后者核对目标来源、计算频带贡献，并生成 `output/primary_loss_comparison_20261007/AUDIT.md`。

电路求值采用独立算术路线：Case1使用并联RLC有理表达式，Case2使用每个并联模块的有理表达式，自设计串并联递归使用逐级阻抗合并，桥式网络使用内部节点Kirchhoff方程。误差使用hypot、atan2和模长比的dB转换，未调用原优化损失函数。检查原始运行来源哈希、末代选解、历史最小目标、选中参数/曲线、逐seed交叉误差和跨seed均值。

Case1/seed2300补充了原180点的逐点欧姆距离、累计贡献和四个频带贡献。两档密集网格仅用于另定义的log频率积分复核，不进入优化，不替换原始D。

运行环境沿用 `tmp/curve_refinement_deps` 中的NumPy、SciPy、Matplotlib与Pillow；Windows请使用UTF-8读取资料。原优化结果、目标、α和种子保持不变。公开页面包含CSV与机器核查记录，未发布服务器凭据或原始优化包。
