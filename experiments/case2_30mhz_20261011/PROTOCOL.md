# 按老师要求，将Case2正式拟合上限改为30 MHz

本轮优化前固定设置。保留原CSV中f<=30,000,000 Hz的183个真实测点，低频起点40 Hz，末点29 MHz。仅排除30 MHz以上18点，不插值、不平滑、不剔除范围内异常点。区别于上轮10kHz–30MHz的108点诊断，不设新的低频截止。

Case1最高1 MHz，不需重跑。Case2运行WSMSE当前标量NSGA-II、WSMSE传统GA、MAG/PHA双目标NSGA-II三方法，各100seed（2300–2399），种群150，1000代；原300代预算阶段单独保存。共300次、45,000,000次候选评价。原参数边界、alpha=17.38、log10编码、SBX和PM设置不变，不加入辅助目标、精修或真值初始化。

同seed初始种群完全相同。双目标每seed末代选归一化非支配前沿的最大凸垂距膝点，退化情况明确标记；跨100seed选代表中统一WSMSE最小者。图同时展示目标、WSMSE传统GA、WSMSE当前框架、双目标膝点，全部限制在30 MHz以内。300代与1000代分别报告，不混合预算。

核验全部初始化、末代目标、损失与预算，并独立重算全部阶段代表。将上轮40Hz–110MHz训练的相同seed最终代表，在同一183点重新评分，用于判断改变上限的实际影响；不能直接拿不同频率点上的原训练分数比较。

本轮结果用于替代此前Case2超30MHz部分的拟合结论，不能再把高于30MHz的未拟合曲线当作本任务缺陷。原96点坐标仍缺失，本轮不冒充精确论文复现。
