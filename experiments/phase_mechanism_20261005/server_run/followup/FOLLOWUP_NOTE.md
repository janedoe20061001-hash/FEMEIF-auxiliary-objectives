# 首轮诊断后的追加检查

首轮诊断发现：Case1 的 I-03+II-02 总相位误差约 75% 来自符号错配点，但相对基线的均值增加不能简单归结为这些点。因此追加两个只读检查，明确属于看过结果后的探索：

1. 将同种子相位误差变化精确拆成四种原节点状态：两组都符号正确、两组都错误、组合修复了基线错误、组合引入了新错误。两组分开计算“同号/错号”的差值存在类别迁移，不能直接当作因果贡献；四状态分解保留这种迁移。
2. 在相同原节点上比较两个诊断量：目标范围归一化幅相曲线的带方向割线差，以及单独相位割线差。这里按主值相位原定义取相邻差，不作展开；Case2 存在分支风险。先前 Im(Z'/Z) 使用对复数曲线求差分后再除以 Z，有限网格上不等于先取相位再求差分，不能混称同一个数值指标。

只比较这些明确对应“坐标与方向信息”的诊断量，不扫描窗口、权重或阈值；未进行优化，不能据高相关宣布有效新指标。
