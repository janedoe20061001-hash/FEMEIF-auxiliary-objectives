# 相位改善能力：已有结果上的机制探索

2026-10-05。用户要求解释 I-03+II-02 在 Case1 上相位改善不稳定的原因，并将对比结果用于寻找有相位改善能力的指标。

本轮只在指定服务器读取既有 1,200 次优化的完整种群、初始种群、曲线和历史；不启动新优化，不改主目标或既有选解，不把事后诊断当作新的验证集。旧 Case1 独立组合实验作为历史复核。新建诊断量仅用于分析，不宣称已获得优化收益。

分析在查看本轮诊断结果之前固定如下：

1. 区分相位均值收益弱、种子收益不稳定与明确损害。对全部种子报告，不以挑选曲线代替总体结果。
2. 对共同样本重算 I-03、II-01、II-02、R-05-C，检查辅助项下降时相位是否下降；相关性按种子为单位汇总。跨选中解偏 Spearman 仅为描述，秩线性残差不代表完整条件独立。
3. 公式核对：II-02 只保留复导数模长，I-03 只保留区域内正确方向事件的存在性。对 Z+c（实常数 c）的共同不变性给出解析证明和数值示意；它不保证属于既有六支路模型，不能作为优化失败的直接因果证据。
4. 实际输出中的遗漏：逐点相位符号错配、区域内过零位置、复导数方向误差、幅值无关的有符号角速度 Im(Z'/Z)、实部常数偏移解释比例。记录零 I-03 时残余相位误差。
5. 区分搜索与选解：每个种子用基线选中解的幅值误差作为相同预算，比较两组最终种群可达到的最小相位误差，报告无可行解的种子数；另报存在支配基线选中解的候选点但固定 WSMSE 未选它的次数。不能据此改写正式成绩。
6. 固定选解权重的 0.5/1/2/4 倍离线敏感性仅用于诊断，不择优报告为新方法。幅值预算阈值来自同种子基线，不是新优化指标参数。
7. 共同初始种群中检查“主目标两项都更差但辅助项更好”的成对冲突率；它说明排序冲突，不证明搜索时保留该点无益。最终前沿比例同样只作机制线索。
8. 事后结论分为公式事实、样本证据、待检验机制。输出面向设计的必要关注点、可淘汰解释，以及至多两个后续候选方向；不凭相关系数宣布某个新损失有效。

所有探索性区间为按种子配对 bootstrap 95% 区间，非同时覆盖区间；与先前正式 60 项 Holm 推断分开。诊断未独立预注册，不使用“确认了因果”的措辞。
