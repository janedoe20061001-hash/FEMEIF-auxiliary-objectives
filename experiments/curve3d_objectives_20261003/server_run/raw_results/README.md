# 把阻抗谱作为三维曲线：冻结的候选定义与正式实验

目的：找到能帮助原有幅值、相位两项目标一起下降的辅助目标，不是把某个新指标本身优化得更小。以下五个方向各有两种预先规定的坐标，共十项候选；不挑转折点，不规定事件数量。

## 1. 共同坐标和离散曲线

原始点为 $(f_i,R_i,X_i)$，其中 $R_i=\Re Z_i$，$X_i=\Im Z_i$，星号表示目标谱，帽号表示拟合谱。原始频率点不删减、不增加。

$$u_i=\frac{\log_{10}f_i-\log_{10}f_1}{\log_{10}f_N-\log_{10}f_1},\quad h_i=u_{i+1}-u_i.$$

频率跨度以数量级计算：每一个十倍频率区间的长度相同，避免原始 Hz 坐标让高频段几乎占据全部长度。这是选择，不是“唯一正确”的度量。

两种阻抗坐标变换 $T$：

$$T_{\rm LIN}(y)=y,\qquad T_{\rm ASH}(y)=\operatorname{asinh}(y/S),\quad S=\operatorname{median}_i|Z_i^*|.$$

`asinh` 是反双曲正弦，不是 `asin`。它是奇函数，负值仍为负值、零仍为零；小值近似线性，大值近似带符号的对数，所以适合有正负号的实部、虚部。实现使用数值库的 `arcsinh`，不直接计算易相消的对数表达式。$S$ 用目标谱的中位幅值固定，是为了定义压缩的尺度；这一选择仍需要实验检验，不能声称不存在任何建模约定。

对每种 $T$，只用目标谱计算公共尺度：

$$a_R=\min_i T(R_i^*),\quad b_R=\max_i T(R_i^*)-a_R,$$
$$a_X=\min_i T(X_i^*),\quad b_X=\max_i T(X_i^*)-a_X,$$
$$p_i(Z)=\left(u_i,\frac{T(R_i)-a_R}{b_R},\frac{T(X_i)-a_X}{b_X}\right).$$

同一组目标谱和所有候选都使用同样的 $a,b,S$；候选坐标可以超过 $[0,1]$，不裁剪。**不能分别对每条拟合曲线归一化，否则会掩盖错误的幅度范围。** 目标三个坐标的跨度都为 1，避免 Hz 和 Ω 单位直接比较；这等于明确选定了坐标相对尺度，并非证明三个方向具有相同物理重要性。两案例的目标轴均不退化。若目标轴跨度为零，应重新定义问题，代码报错，不偷偷加一个任意小常数。

$p(u)$ 为原始频率点间的分段线性三维曲线。幅值、相位原主目标仍使用原协议的未加权逐点平均，辅助指标中的 $u$ 积分不改变主目标。

## 2. 五个方向的完整计算公式

### D-01 全频率对距离：看相隔很远的两段是否关系正确

$$w_1=h_1/2,\quad w_N=h_{N-1}/2,\quad w_i=(h_{i-1}+h_i)/2\ (1<i<N),$$
$$d_{ij}(Z)=\|p_i(Z)-p_j(Z)\|_2,$$
$$L_{\rm D01}=\sqrt{\frac{\sum_{i<j}w_iw_j[\widehat d_{ij}-d_{ij}^*]^2}{\sum_{i<j}w_iw_j(d_{ij}^*)^2}}.$$

遍历所有频率点对，不挑“代表性”的若干个点；$w_i$ 是原始对数频率网格的梯形积分权重。距离矩阵保留远端之间的整体结构，不仅检查相邻转折。使用距离而非平方距离，公式是本项目适配，不等同于文献中标准平方 EDM 的损失。弱点：整体平移、旋转、镜像不会改变距离矩阵；这项不能独立判断绝对位置和方向，必须保留原主目标。[距离矩阵的几何性质原始综述](https://arxiv.org/abs/1502.07541)。

### D-02 整体坐标变化关系：看整条曲线向哪些方向展开

$$\mu=\sum_{i=1}^{N-1}\frac{h_i}{2}(p_i+p_{i+1}),\quad a_i=p_i-\mu,\quad b_i=p_{i+1}-\mu,$$
$$C=\sum_{i=1}^{N-1}\frac{h_i}{6}\left(2a_ia_i^\top+a_ib_i^\top+b_ia_i^\top+2b_ib_i^\top\right),$$
$$L_{\rm D02}=\frac{\|\widehat C-C^*\|_F}{\|C^*\|_F},\qquad \|M\|_F=\sqrt{\sum_{j,k}M_{jk}^2}.$$

这恰好等于 $C=\int_0^1[p(u)-\mu][p(u)-\mu]^\top du$，不是把样本点当成独立重复测量的无偏统计估计，因而不使用 $N-1$ 修正。对角项记录三个坐标各自的整体变化幅度；非对角项记录频率、实部、虚部是否一起变化。它是全曲线二阶矩，不用阈值或主成分保留数量。弱点：很多不同曲线可有相同矩阵，不保证细节相同，且平移不改变它。

### D-03 三平面有向面积：看曲线整体偏向和绕行方向

$$r_i=p_i-p_1,\quad A=\frac12\sum_{i=1}^{N-1}r_i\times r_{i+1},\quad L_{\rm D03}=\|\widehat A-A^*\|_2.$$

`×` 是三维叉积。开放曲线用起终点之间的直线闭合，因平移到起点，最后一条闭合边对上述和式贡献为零。$A$ 的三个分量依次对应 $(R,X)$、$(X,u)$、$(u,R)$ 平面的带符号面积；三项来自三维空间的三个坐标平面，不是人为要求三个事件。有向面积与路径签名的二阶反对称部分有关，但这里仅比较面积，**不是完整路径签名**。[路径签名原始教程](https://arxiv.org/abs/1603.03788)。弱点：反向绕行的面积会抵消，闭合直线是明确的几何约定，不是实际测量到的曲线；相同面积不保证相同形状。不用可能为零的目标面积作除数。

### D-04 走向与变化快慢：看每个频段向哪里走、走得多快

$$v_i=\frac{p_{i+1}-p_i}{h_i},\quad q_i=\frac{v_i}{\sqrt{\|v_i\|_2}},$$
$$L_{\rm D04}=\frac{\sum_{i=1}^{N-1}h_i\|\widehat q_i-q_i^*\|_2^2}{\sum_{i=1}^{N-1}h_i\|q_i^*\|_2^2}.$$

$v_i$ 是对数频率坐标上的空间变化速度；$q_i$ 的方向与 $v_i$ 相同、长度为 $\sqrt{\|v_i\|_2}$，同时比较方向和变化快慢。由于频率坐标的导数恒为 1，$\|v_i\|>0$，不需要人为稳定常数。分母等于目标三维曲线弧长。整条曲线的所有频段都参与，仍是一阶变化指标，不能把它包装成只看宏观结构的指标。它借用 SRVF 表示，**不优化旋转或任意频率扭曲，也不是完整弹性形状空间的测地距离**。[作者的 SRVF 理论说明](https://www.math.fsu.edu/~whuang2/pdf/Elastic_Shape_Analysis_techrep.pdf)。弱点：对噪声和微小振荡较敏感，绝对平移不影响它。

### D-05 按弧长对应的形状：看整条空间曲线的进程是否一致

$$\ell_i=\|p_{i+1}-p_i\|_2,\quad \mathcal L=\sum_i\ell_i,\quad s_1=0,\quad s_k=\frac{\sum_{i<k}\ell_i}{\mathcal L},$$
$$\gamma_Z(s_k)=p_k(Z),\quad L_{\rm D05}=\int_0^1\|\gamma_{\widehat Z}(s)-\gamma_{Z^*}(s)\|_2^2ds.$$

每条曲线按自己的累计弧长百分比重新标记位置，$\gamma$ 在相邻 $s_k$ 间线性插值。目标和拟合的两套 $s_k$ 取并集 $t_1<\cdots<t_M$，令 $e_j=\gamma_{\widehat Z}(t_j)-\gamma_{Z^*}(t_j)$，则无需指定重采样数量：

$$L_{\rm D05}=\sum_{j=1}^{M-1}\frac{t_{j+1}-t_j}{6}\left(\|e_j\|_2^2+4\left\|\frac{e_j+e_{j+1}}2\right\|_2^2+\|e_{j+1}\|_2^2\right).$$

区间内差向量线性、平方距离为二次函数，所以该 Simpson 公式是精确积分。频率坐标仍留在三维点中，错频不是免费免罚；没有 DTW 窗口或额外的自由配准参数。弱点：各自归一弧长会减弱总长度差的直接约束；一段曲线变化会改变后面各段的对应关系，可能过度传播局部误差。它是本项目的直接几何构造，不声称文献已验证其用于阻抗拟合有效。

## 3. 有考虑但暂不正式测试的方向

|方向|暂缓的原因|
|---|---|
|曲率、挠率、Frenet 标架|二、三阶导数对离散噪声敏感；近直线、近零曲率处挠率不稳定。平滑窗口、剔除阈值又会引入需要解释的参数。|
|曲率峰数量、拐点数量、持续若干事件|直接重现用户要求剔除的问题，不能给数字编一个事后理由。|
|高阶路径签名|阶数选择需要论证，复杂度迅速上升。先用具有直观几何意义的面积，而非任意截断阶数。|
|仅比较总弧长、包围盒或 PCA 特征值|过度压缩；非常不同的曲线也可拥有相同结果。保留完整协方差比只留若干 PCA 分量更透明。|
|普通 $\log R,\log X$|负值和零无定义；不得加任意平移量让它能取对数。|
|纯 Nyquist 曲线任意旋转/缩放后配准|可能把电阻偏置、绝对量级、频率位置的实际拟合错误消掉。|
|三维 Fréchet 距离|有合理定义，保留为后续候选；这轮先区分全局关系、矩、面积、速度、弧长五种机制，避免所有新增项都挤在路径匹配上。|

## 4. 冻结的正式实验

- 每 Case：原双主目标基线 + 十个单辅助组，共 11 组；每组 seeds 0–99。共 2,200 次完整运行。
- Case I：原始 180 个频率点，原六 RLC 电路，种群 200、300 代，每运行 60,000 次评估。
- Case II：原始 201 个测量点，原 15 参数电路，种群 150、300 代，每运行 45,000 次评估。
- 总计 115,500,000 次评估。复用历史完整算法、边界、初始化、交叉、变异；所有目标参与 NSGA-II 的选择，不在进化期间加权合成标量。
- 最后仍按原固定 WSMSE 从最后一代选同一个体，Case I 相位权重 25.12、Case II 为 17.38；不是分别挑两项各自最好个体。
- 同 seed 各组初始种群完全相同。基线本次同环境重跑，再与历史全部 100 seeds 的主误差核对。
- 先保存定义和配置，再运行；不根据中途结果改变坐标、阈值、种子或预算。这一轮不做双、三辅助组合，避免把坐标和组合效果混在一起。
- 报告两项原主误差均值及相对基线下降百分比，配对 seed 自助 95% 区间，40 项双侧 Wilcoxon 检验的 Holm 修正，以及双项同时改善 seed 数。区间未做同时覆盖修正。
- 审计每次完整 300 代、评估数、初始种群、最后完整种群目标复算、最终选择和源代码指纹。原始记录全部归档并校验下载 SHA256。

即使本轮某项在两 Case 都改善，它仍是同一批数据上探索筛选得到的候选；多重检验只限制本轮统计比较，不能消除历轮选指标的偏差，也不等同于新数据独立验证。
