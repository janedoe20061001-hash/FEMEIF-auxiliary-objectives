# 分析实现说明（正式结果汇总之前）

本文件补充实现细节，不改变冻结优化输入或运行方案。

1. 双目标敏感性同时保留原采样和两组新增采样的均衡选解，共3条；加上9条主要选解，每seed共同检查12条解析曲线。
2. 两档网格先用refinement 1/2；不稳定的整块seed继续2/4、4/8。稳定判据为幅相RMSE及平均Ω距离相对变化≤1%，分母底值分别0.1dB、0.5°、1e−8Ω；幅相漏失和新增计数相同。仍不稳定的行不删除，不据此支持精确结构优势。
3. 桥式独立验证用两个内部节点的Kirchhoff电压方程，输入电流由通向参考端的电流求和，避免“1−节点电压”在近1时的消减误差。没有修改优化器的电路计算。
4. 每电路区间按预定seed块bootstrap。跨电路集合中，9个自设计共享20个seeds 2300–2319，Case1额外有80个seeds 2320–2399；汇总区间联合重采样共享20个seed，Case1其余80个seed在独立层重采样，保持同seed跨电路的联动，不将它们视为互不相关的重新实验。各电路均值仍等权，Case1不是5倍权重。该区间条件于固定电路集合，不代表随机电路总体。
5. 另报告候选曲线的训练点折线缺口，用来区分目标采样可靠与任意拟合候选的采样可靠。目标窄峰核心权重记录在TARGET_INFORMATION.json，只作解释，不反过来调权、调频点或改变优化选择。
