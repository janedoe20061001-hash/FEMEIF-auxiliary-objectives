# 全区间弧长与逐段弧长：冻结的探索方案

上一轮两端对称累计弧长没有明确优于原累计弧长。本轮保留原累计弧长作对照，提出两个针对不同问题的变体。数学上改变约束并不保证改善搜索。正式优化前固定本文件、代码、配置与检查结果。

|指标|检验的问题|公式中的变化|主要限制|
|---|---|---|---|
|R-05-C 累计弧长|较有希望的原方向能否重复|不变，作为对照|固定从低频端累计，长度不辨方向|
|G-05-I 全区间弧长误差|从固定端点累计是否使早期偏差传播到后面，改变任意频率区间的比较后是否更有帮助|比较所有频率对之间的沿曲线距离|同样不辨方向，对起点附近一小段的改变可能不敏感；不声称严格包含旧指标|
|G-05-H 逐段弧长平方根误差|累计后某些正负长度偏差抵消；去掉旧 SRVF 指标中的方向惩罚是否更有帮助|逐段比较弧长的平方根，是非归一化弧长测度的 Hellinger 型差异|仍可能敏感于噪声、窄峰和相位跳变；没有位移容忍，不能保证比累计量稳定|

新指标都是对已有数学量的任务适配，不宣称原创距离或已获文献验证的阻抗目标。不能把原来试过的 SRVF 换名当新指标，本文明确推导它与 G-05-H 的关系。

## 公用坐标与原主目标

目标 $Z_i^*$，候选 $\widehat Z_i$，频率 $f_1<\cdots<f_N$；$m_i(Z)=20\log_{10}(|Z_i|/(1\,\Omega))$，$\phi_i(Z)=\operatorname{Arg}Z_i$，单位为弧度。用目标的最小值 $a_j$ 和极差 $b_j$ 定义 $y_{i,j}(Z)=[x_{i,j}(Z)-a_j]/b_j$，其中 $x_m=m,x_\phi=\phi$。

$$u_i=\frac{\log_{10}f_i-\log_{10}f_1}{\log_{10}f_N-\log_{10}f_1},\quad h_i=u_{i+1}-u_i,\quad p_i(Z)=(u_i,y_{i,m},y_{i,\phi}).$$

目标与候选共用目标坐标尺度；三个轴的相对尺度是一项建模约定，并非无需解释的物理定律。相位沿用主值，不展开，保留 Case2 全部 201 个测量点。目标两轴均非恒定，不加入 epsilon。主目标始终为

$$E_m=\frac1N\sum_i(\widehat m_i-m_i^*)^2,\qquad E_\phi=\frac1N\sum_i(\widehat\phi_i-\phi_i^*)^2.$$

## 原累计弧长

$$\ell_i(Z)=\|p_{i+1}(Z)-p_i(Z)\|_2,\quad B_1=0,\quad B_k(Z)=\sum_{i<k}\ell_i(Z),\quad T^*=B_N(Z^*),\quad e_k=\frac{\widehat B_k-B_k^*}{T^*}.$$

在原频率结点之间线性插值 $B,e$，记

$$\mathcal I(e)=\int_0^1 e(u)^2du=\sum_{i=1}^{N-1}\frac{h_i}{3}(e_i^2+e_ie_{i+1}+e_{i+1}^2),\qquad L_B=\sqrt{\mathcal I(e)}.$$

## G-05-I：任意两个频率之间，曲线走过的距离

对于 $u\le v$，沿曲线走过的长度为 $B(v)-B(u)$，两条曲线的该区间长度差除以目标总长为 $e(v)-e(u)$。平方后可以对整个单位正方形积分：

$$L_I^2=\int_0^1\int_0^1[e(v)-e(u)]^2\,du\,dv.$$

令

$$\bar e=\int_0^1e(u)du=\sum_i\frac{h_i}{2}(e_i+e_{i+1}),$$

展开双重积分得到

$$L_I=\sqrt{2\int_0^1[e(u)-\bar e]^2du}=\sqrt{2\mathcal I(e-\bar e)}.$$

因此可以精确线性时间计算，不抽样频率对、不选窗口、不规定区间数量。系数 2 来自展开双重积分。计算时先减均值再积分，避免两个接近的大数相减。

它比较的是沿曲线的内在距离；以前的全频率对距离 D-01 比较两点间的直线距离，两者不同。所有频率对按归一化对数频率均匀积分，是预先规定的权重约定。它与原指标满足 $L_I^2=2(L_B^2-\bar e^2)$，是重新分配累计长度误差的惩罚，而非增加全新的独立物理信息。

若 $e(u)=cu$，则 $L_I=|c|/\sqrt6$；能够反映总长变化，但不是额外的终点惩罚。若局部长度偏差发生在很窄的端点区间，随后 $e$ 近似常量，中心化后惩罚可能很小。必须检验是否因此忽略有用信息。

## G-05-H：逐段弧长平方根误差

每段弧长密度为 $s_i(Z)=\ell_i(Z)/h_i$，即单位对数频率内曲线走过的长度。定义

$$L_H=\sqrt{\frac1{T^*}\sum_i h_i[\sqrt{\widehat s_i}-\sqrt{s_i^*}]^2}=\sqrt{\frac1{T^*}\sum_i[\sqrt{\widehat\ell_i}-\sqrt{\ell_i^*}]^2}.$$

平方根来自 Hellinger 距离的密度表示，不是拟合出来的指数。这里的弧长测度总质量可以不同，因此没有将每条候选曲线归一化为概率分布，也不能宣称 $L_H$ 被限制在 $[0,1]$。

为看清它保留的信息，令 $\widehat T=\sum_i\widehat\ell_i$、$\widehat w_i=\widehat\ell_i/\widehat T$、$w_i^*=\ell_i^*/T^*$，则

$$L_H^2=\left(\sqrt{\widehat T/T^*}-1\right)^2+2\sqrt{\widehat T/T^*}\left(1-\sum_i\sqrt{\widehat w_iw_i^*}\right).$$

这只是恒等分解，实际计算无需候选专属归一化。第一项比较总长度，第二项比较长度沿频率的分配，两项系数由恒等式给出。

若同一条直线段同步细分成比例为 $\lambda$ 与 $1-\lambda$ 的两段，细分前后的 $L_H$ 相同；这是对已有分段线性曲线的细分不变性，不等于在未知高曲率区新增真实测量点后指标不变。

## 与已经做过的 SRVF 指标的关系

原 D-04-LP 是 $L_{\rm SRV}=T^{*-1}\sum_i h_i\|\widehat q_i-q_i^*\|^2$，其中 $q_i=v_i/\sqrt{\|v_i\|}$、$v_i=(p_{i+1}-p_i)/h_i$。令 $t_i=(p_{i+1}-p_i)/\ell_i$ 为单位切向量，则

$$L_{\rm SRV}=L_H^2+\frac2{T^*}\sum_i\sqrt{\widehat\ell_i\ell_i^*}(1-\widehat t_i^\top t_i^*).$$

本轮 G-05-H 只保留长度部分，去掉方向部分。此前 SRVF 效果较差；本轮检验其中长度部分是否仍有用，不能据旧结果预先断言失败来自方向项。外层平方根与旧 SRVF 原返回值不同，可能影响拥挤距离，因此不能将全部实验差异归因于方向项。

上述两个指标都不比较整体幅值／相位平移，且长度不辨上下方向，所以原双主目标不可去掉。

## 文献与推导来源

- Hellinger 距离在有限非负测度上的平方根密度定义，见 Liero、Mielke、Savaré 的[原始论文第 2 节](https://arxiv.org/pdf/1509.00068)。这里只用 Hellinger 部分，没有引入 Hellinger–Kantorovich 的运输／反应参数。
- SRV 表示见 Srivastava 等人的[原始论文](https://pubmed.ncbi.nlm.nih.gov/20921581/)。本项目保留频率对应关系，不求旋转或重新参数化。
- 全区间恒等式、弧长测度适配及上述分解由本文直接展开推导；文献不提供这些损失改善本项目阻抗拟合的证据。

## 预先确定的正式实验

- 每 Case：基线、原累计弧长、G-05-I、G-05-H，共 4 组；每组配对种子 1100—1199，共 800 次完整运行、42,000,000 次评估。
- Case1 为种群 200 × 300 代，全部 180 原频点；Case2 为种群 150 × 300 代，全部 201 原点。原电路、参数边界、NSGA-II 算子、主目标及最后按 WSMSE 选同一个体的方法完全沿用。
- 3 个辅助组对基线，2 个新组对原累计弧长：每 Case 5 项比较 × 2 项主误差，共 20 项双侧配对 Wilcoxon 检验统一 Holm 修正，阈值 0.05。
- 10,000 次配对种子 bootstrap 给出 MSE 均值比例下降的 95% 区间，未作同时覆盖校正；两种统计针对的量不同，不以区间替换预定检验。
- 主要判据：相对基线和相对原累计弧长均比较两个 Case 的两项主误差。单个主误差／单个 Case／只有辅助误差改善，不称通用改进。
- 软件检查只验证公式、反例和完整初始种群，不做缩小预算的拟合筛选。冻结后不改公式，不按中间结果追加候选、改种子或预算。
- 数据仍是原两条曲线，本轮是受历史探索启发的新假设检验。多重比较校正不消除跨轮选择偏差，也不能代替新测量／噪声验证。
