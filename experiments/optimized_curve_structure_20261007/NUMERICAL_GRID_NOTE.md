# 网格检查与修复记录

初始网格沿用参数扰动研究的极点/零点方法，并对全部已知解析目标作两档加密。先导检查 Case1 / seed2300 的距离组发现：峰谷计数一致，但欧姆积分在两档网格间变化约3.18%。这属于数值积分可靠性问题，不能当成优化指标的科学差异。

参数扰动研究的网格为原样本范围服务；优化器的宽边界可以产生远窄于原样本的高Q模式。原方法把模态邻域宽度截到1e-6，而且窄邻域与远处背景之间可能形成很大的梯形积分单元。

修复仅用于诊断：保留同一解析目标、选中个体与主误差，模态宽度下限降到浮点可解析的1e-12；增加简单RLC单元的精确1/(2π√LC)频率与Q；模态外围加入按偏移量几何递增的采样，避免用大梯形跨越长尾。背景、模态内点及尾部点均作两倍加密复核。first_grid 输出完整保留。

同一先导解修复后，欧姆积分为5.05443 / 5.05433 Ω，两档变化约0.002%；这说明修复有效。该积分使用log频率权重，不能与原训练频点的等权MAE_Z混作同一数值。

额外记目标/拟合的解析密集幅值与原采样折线之间的最大偏差（dB）。它用于分辨目标自身采样不足与拟合在测点间产生额外结构；Case2无测点间真值，不计算目标采样缺口。密集网格没有参与任何优化，也未修改α或种子。
