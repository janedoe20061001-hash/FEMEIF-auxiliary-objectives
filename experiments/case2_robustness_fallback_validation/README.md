# Independent robustness fallback validation

Seeds 500--599 independently compare baseline, I-03+II-02, I-03, P-03+P-04,
and P-03+P-05 under high noise and a seed-specific contiguous 20% frequency
gap.  These groups were selected only after the full seeds 400--499 robustness
screen, so this batch tests whether the apparent condition-specific winners
replicate out of sample.
