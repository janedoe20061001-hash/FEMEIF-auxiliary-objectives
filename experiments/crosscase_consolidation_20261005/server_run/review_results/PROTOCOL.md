# 2026-10-05 跨 Case 统一比较：启动前方案

用户于 2026-10-05 明确恢复必要实验并指定服务器。本批检验两类局部组合、累计弧长与连续频段平均残差；不使用固定转折/过零数量指标。

每个 Case 六组：双主目标基线、I-03+II-01、I-03+II-02、R-05-C、T-01、G-01-LP。同一组标签在两个 Case 使用同一公式。两种局部组合均在两 Case 运行，避免先按 Case 挑赢家后直接宣称跨案例有效。

每组 100 个新配对种子 2000–2099，共 1200 次优化、6300 万次评价。Case1 种群 200、300 代；Case2 种群 150、300 代。所有原频点、电路、参数边界、算子、主值相位与固定 WSMSE 选解权重沿用历史协议。Case1 为 180 点重构合成目标，不声称复现原 PDF 的 401 点；Case2 保留原始 201 点实测数据。

T-01 沿用 2026-10-04 的连续定义：目标范围固定的 dB/弧度相位残差，原频率节点之间分段线性插值；所有连续区间的带符号平均残差平方积分后开方。采用预计算正二次型；同一网格段内部的三角积分精确，不同段的矩形积分用 Gauss 求积。按 4、8、16、32 阶检查，至少 16 阶且与前一阶完整初始种群评分最大相对差低于 1e-6 才冻结。该阈值仅控制数值求积精度，不是特征尺度。解析常数/线性样例、非均匀网格、独立自适应积分、倒序及细分检查也必须通过。未通过则停止，不能跳过检查启动优化。

G-01-LP 是旧 G-01 的同坐标对照：对目标范围归一化的 dB/相位残差做双向累计，再沿原节点用梯形积分求平方损失，无外层开方。它与旧复相对残差 G-01 的坐标不同，使用独立标签。T-01 与它的直接比较检验整套汇总定义（包含外层变换）的差异，不将差异全部归因于区间平均，也不把相关系数视为因果机制。

统计在运行前固定：每 Case 六组全部 15 对直接比较，每对两个主误差，共 60 项双侧配对 Wilcoxon 检验统一 Holm 校正，阈值 0.05。均值比例下降采用 10000 次配对种子 bootstrap 95% 区间；区间不做同时覆盖修正，检验与区间的估计对象不同。主表保留全部种子，两个误差取自同一选中个体。均值、中位数、两项同时改善的种子数、耗时、前沿诊断都报告；不依据中间结果更换种子、候选或选解权重。

主要问题依次为：相对基线是否改善两项主误差；累计弧长与两种局部组合谁更好；T-01 是否改善基线，且相对同坐标累计残差/原弧长提供收益。未显著不等于等效。探索性新候选的结果不能代替独立新测量验证。

后处理固定：在共同基线初始种群、共同基线最终种群计算相关性，按种子分别算 Pearson/Spearman 并汇总中位数与四分位数；另报每次固定选中一个解的跨种子相关性。常数指标返回未定义并报告有效种子数，不用零替代。分频段误差用逐原频点误差剖面及等分 log 频率三段作描述，不修改拟合目标；相位分支附近的贡献单独报告。优化/初始/最终样本分别展示，不把同种群个体当独立重复。

完整初始种群、每代汇总、最终种群、固定选解和代码指纹均保留。完成后逐次重算目标与选解、检查代数/评价数及配对初始化；另用独立公式核对核心辅助损失。打包原始结果并下载核验 SHA256。
