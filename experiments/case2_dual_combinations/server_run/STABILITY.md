# 配对 seed 稳定性分析

数据阶段：Case2 两套三指标集合迁移；seed 0–99；每组 100 次运行。
每个 seed 的候选组误差减去同 seed 的 baseline 误差，负数表示改善。幅值单位 dB²，相位单位 rad²。两个误差始终来自同一个 WSMSE 选中个体。
按 seed 成对重采样 20000 次，两项指标使用相同重采样索引；固定分析随机种子 20260916。
报告百分位 bootstrap 的单项 95% 区间，以及覆盖8个组合×两项共16个比较的 Bonferroni 调整区间（每项约99.688%）。后者旨在控制整组判断的误报，但 bootstrap 覆盖率是近似的。
两套组合固定为Case1已实验的集合；本轮检验在Case2上的适用性，不能归因于噪声这一个因素。区间跨零表示证据不足，不表示证明没有效果。
