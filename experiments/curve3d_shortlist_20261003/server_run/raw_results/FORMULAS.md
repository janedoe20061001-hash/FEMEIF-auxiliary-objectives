# 有希望的三维全局指标：完整计算公式

公式与已经做过的正式实验保持一致，不为本轮重新调参。所有量均为误差，越小越好。主要候选是累计弧长及两端对称累计弧长；方向分解为次级候选；累计面积为对照。

## 一、公用记号与坐标

设原频率为 $0<f_1<\cdots<f_N$，$Z_i^*$ 为目标阻抗，$\widehat Z_i=Z(f_i;\theta)$ 为拟合电路的阻抗。星号表示目标，帽子表示候选；$\mathrm i$ 是虚数单位，$i$ 是采样下标。阻抗以 $1\,\Omega$ 为幅值参考。

$$u_i=\frac{\log_{10}f_i-\log_{10}f_1}{\log_{10}f_N-\log_{10}f_1},\qquad h_i=u_{i+1}-u_i.$$

$$m_i(Z)=20\log_{10}\frac{|Z_i|}{1\,\Omega},\qquad \phi_i(Z)=\operatorname{Arg}(Z_i).$$

$u_i$ 是从 0 到 1 的对数频率；$h_i$ 是相邻点的对数频率间隔。$m$ 是 dB 幅值，$\phi$ 是弧度主值相位。代码沿用 `np.angle`，不展开相位、不把相位差重新绕回 $[-\pi,\pi]$；Case2 的主值跳变也保留。非零阻抗是对数坐标的定义域。

只用目标确定坐标偏移和尺度：

$$a_m=\min_i m_i^*,\quad b_m=\max_i m_i^*-\min_i m_i^*,\qquad a_\phi=\min_i\phi_i^*,\quad b_\phi=\max_i\phi_i^*-\min_i\phi_i^*.$$

$$y_{i,m}(Z)=\frac{m_i(Z)-a_m}{b_m},\quad y_{i,\phi}(Z)=\frac{\phi_i(Z)-a_\phi}{b_\phi},\qquad p_i(Z)=(u_i,y_{i,m}(Z),y_{i,\phi}(Z)).$$

目标与候选用同一把尺子；候选超出 $[0,1]$ 不裁剪，也不以自己的跨度再归一化。本实验目标两轴均非恒定，因此 $b_m,b_\phi>0$；若目标某轴恒定，需另行定义退化问题，不能随意加稳定常数。

对任意标量或向量误差序列 $e_1,\ldots,e_N$，在原结点 $u_i$ 之间线性插值，记

$$\mathcal I(e)=\int_0^1\|e(u)\|_2^2\,du=\sum_{i=1}^{N-1}\frac{h_i}{3}\left(\|e_i\|_2^2+e_i^\top e_{i+1}+\|e_{i+1}\|_2^2\right).$$

标量情形把括号写成 $e_i^2+e_ie_{i+1}+e_{i+1}^2$。$\|\cdot\|_2$ 是欧氏长度，$e_i^\top e_{i+1}$ 是内积，$1/3$ 来自平方线性函数的精确积分，不是调出来的参数。这里线性插值的是**离散误差剖面**；例如累计弧长结点之间的长度剖面，而不是另外对连续电路曲线做自适应弧长积分。

原双主目标保持为

$$E_m=\frac1N\sum_{i=1}^N(\widehat m_i-m_i^*)^2,\qquad E_\phi=\frac1N\sum_{i=1}^N(\widehat\phi_i-\phi_i^*)^2.$$

主目标按原采样点等权平均；辅助指标按 $u$ 积分，两种频率权重并不相同，不能声称只改形状而完全没有频率权重差异。

## 二、主要候选：累计弧长 R-05-C

每一段的三维长度为

$$\ell_i(Z)=\|p_{i+1}(Z)-p_i(Z)\|_2=\sqrt{h_i^2+[y_{i+1,m}(Z)-y_{i,m}(Z)]^2+[y_{i+1,\phi}(Z)-y_{i,\phi}(Z)]^2}.$$

从低频端累计：

$$B_1(Z)=0,\qquad B_k(Z)=\sum_{i=1}^{k-1}\ell_i(Z),\quad k=2,\ldots,N,\qquad T^*=B_N(Z^*).$$

$$e_k=\frac{B_k(\widehat Z)-B_k(Z^*)}{T^*},\qquad L_B=\sqrt{\mathcal I(e)}.$$

完整离散式为

$$L_B=\sqrt{\sum_{i=1}^{N-1}\frac{h_i}{3}\left(e_i^2+e_ie_{i+1}+e_{i+1}^2\right)}.$$

它问的是：“走到同一个频率位置时，拟合曲线和目标曲线已经走过的长度相差多少？”分母一直用目标总长，保留候选总长度不同的信息。$h_i>0$ 保证 $T^*>0$，无需任意 epsilon。

实际优化向量是 $(E_m,E_\phi,L_B)$，不是把三项加成一个人为加权和。局限：幅值变化和相位变化可以在长度中补偿；长度不辨上升下降，也不惩罚整体平移，原双主目标不能去掉。

## 三、主要新变体：两端对称累计弧长 Q-05-B

从当前频率到高频端的剩余长度为

$$C_k(Z)=\sum_{i=k}^{N-1}\ell_i(Z)=B_N(Z)-B_k(Z).$$

定义反向累计误差：

$$\eta_k=\frac{C_k(\widehat Z)-C_k(Z^*)}{T^*}=e_N-e_k.$$

$$L_{B,\mathrm{sym}}=\sqrt{\frac12\left[\mathcal I(e)+\mathcal I(\eta)\right]}.$$

完整离散式为

$$L_{B,\mathrm{sym}}=\sqrt{\sum_{i=1}^{N-1}\frac{h_i}{6}\left[e_i^2+e_ie_{i+1}+e_{i+1}^2+\eta_i^2+\eta_i\eta_{i+1}+\eta_{i+1}^2\right]}.$$

它同时检查“从低频走到这里”和“从这里走到高频”的长度。原单向累计中，靠近高频末端出现的偏差可能只影响很短的积分区间；加入反向累计后也会被较早位置看到。$1/2$ 是两个方向的等权平均，并非优化得到；两端等重要仍是一项建模约定，不是无可争议的物理定律。

实际优化向量为 $(E_m,E_\phi,L_{B,\mathrm{sym}})$。不能保证更抗噪声，主值相位跳变也会进入长度。若候选总长恰好等于目标总长，则 $e_N=0$、$\eta_k=-e_k$，所以 $L_{B,\mathrm{sym}}=L_B$；并不是所有时候都提供新信息。

## 四、次级候选：分轴上升／下降累计量 Q-05-D

对 $j\in\{m,\phi\}$，先计算每段某轴的增量：

$$\Delta y_{i,j}(Z)=y_{i+1,j}(Z)-y_{i,j}(Z).$$

$$P_{k,j}(Z)=\sum_{i=1}^{k-1}\max(\Delta y_{i,j}(Z),0),\qquad D_{k,j}(Z)=\sum_{i=1}^{k-1}\max(-\Delta y_{i,j}(Z),0),\qquad P_{1,j}=D_{1,j}=0.$$

$P$ 只累计上升，$D$ 把下降取正后累计。`max(x,0)` 表示 $x>0$ 时保留 $x$，否则取 0；零是正负的数学分界，不是选出来的事件阈值，也不限定转折次数。用 $D$ 记下降量，避免与采样数 $N$ 混淆。

$$T_j^*=P_{N,j}(Z^*)+D_{N,j}(Z^*),\qquad a_{k,j}=\frac{P_{k,j}(\widehat Z)-P_{k,j}(Z^*)}{T_j^*},\qquad d_{k,j}=\frac{D_{k,j}(\widehat Z)-D_{k,j}(Z^*)}{T_j^*}.$$

$$q_k=(a_{k,m},a_{k,\phi},d_{k,m},d_{k,\phi}),\qquad L_{PD}=\sqrt{\frac12\mathcal I(q)}.$$

$$L_{PD}=\sqrt{\sum_{i=1}^{N-1}\frac{h_i}{6}\left(\|q_i\|_2^2+q_i^\top q_{i+1}+\|q_{i+1}\|_2^2\right)}.$$

它比较幅值和相位“到该频率累计上升多少、下降多少”，以各轴目标总变化量为尺度。$1/2$ 对应两个坐标轴的等相对权重，**不是四项的 $1/4$ 平均**；保持原实验定义。频率轴在目标与候选间相同，其上升／下降误差恒为零，不再计入。

它等价于总变化量误差和相对起点位移误差的组合，不能称完全独立的新物理信息。对噪声与起点误差敏感；本轮不运行此指标，留待主要候选验证后再考虑。

## 五、保留的对照：全过程累计有向面积 R-03-C

$$r_i(Z)=p_i(Z)-p_1(Z),\qquad A_1(Z)=0,\qquad A_k(Z)=\frac12\sum_{i=1}^{k-1}r_i(Z)\times r_{i+1}(Z).$$

$$v_k=A_k(\widehat Z)-A_k(Z^*),\qquad L_A=\sqrt{\mathcal I(v)}=\sqrt{\sum_{i=1}^{N-1}\frac{h_i}{3}\left(\|v_i\|_2^2+v_i^\top v_{i+1}+\|v_{i+1}\|_2^2\right)}.$$

$\times$ 是三维叉积。面积向量的三个分量分别对应幅值—相位、相位—频率、频率—幅值平面的有向投影面积。每个前缀用直线闭合回首点，$1/2$ 来自三角形面积，不是调参。它看“走到每个频率时累计围出了多少有向面积”，减少只看最终面积而忽略中间变化的问题，但每个前缀内仍可能正负抵消，面积也不能唯一确定曲线。

该指标 Case1 有改善证据、Case2 较弱；不能因与主目标相关性高就判定优化作用更好。本轮只展示公式，不重新加入候选实验组。

## 六、直接计算的步骤

1. 在全部原频点算候选复阻抗，计算 dB 幅值和弧度主值相位。
2. 用目标固定尺度组成三维点列，不按候选自身重新归一化。
3. 在原结点上计算段长、累计长，以及需要时的正负变化或面积前缀。
4. 与目标同频率前缀相减，形成误差剖面。
5. 用上面的精确积分公式算平方积分，再开平方。
6. 保留原双主目标；本轮每组只加一个弧长辅助误差。
