# 收窄候选后的固定复核方案

## 在正式运行前确定

只比较三个组：原双主目标；双主目标＋累计弧长 R-05-C；双主目标＋两端对称累计弧长 Q-05-B。不加入面积、方向分解、双辅助组合或新的公式。现有探索结果用于提出这次比较，不把本轮称作对全项目探索偏差的完全消除。

- 两个 Case 各组 100 个配对种子，固定为 1000—1099；三个组使用同 seed 相同初始种群。
- Case1：200 个个体、300 代、180 个原频点、18 个原参数。
- Case2：150 个个体、300 代、201 个原测量点、15 个原参数。
- 共 600 次完整运行、31,500,000 次评估，不做缩小预算拟合。
- 完全保留原数据、电路、参数边界、幅值／相位 MSE、NSGA-II 算子。最终从每次运行最后种群按原 WSMSE 选同一个个体：相位权重分别为 25.12、17.38。它只用于固定选解，不是新增的优化目标权重。
- 不删点、不展开相位、不截频段、不设置平滑窗口，不根据本轮结果改变公式和预算。
- 每 Case 三项预先确定的比较：累计弧长对基线；对称累计弧长对基线；对称累计弧长对累计弧长。
- 以上 3 个比较 × 2 个 Case × 2 个主误差，共 12 项双侧配对 Wilcoxon 检验，统一 Holm 修正。判定水平沿用 0.05，不根据结果更换。
- 同时报 100 次运行的均值、中位数、MSE 均值比例下降、10,000 次配对种子 bootstrap 95% 区间；区间未作同时覆盖校正。检验针对配对差异，不等价于直接检验均值比例。
- 要称对称变体进一步优于累计弧长，需两个 Case 的两项主误差下降且对应修正检验均支持改善；不能只凭一个 Case、一个误差或 WSMSE。
- 若没有明确增量支持，不宣称等效，不自动换一个更复杂指标，也不临时扩展候选。

本轮是新随机种子下的同数据复核，不是新电路／新测量／抗噪声验证。尚未获得重复测量或仪器噪声依据，不任意指定噪声强度。已有 Case2 原点的可行域问题继续保留并单独说明。

## 有希望的指标及公式

详见 [候选公式](FORMULAS.md)。本轮只运行其中的累计弧长与两端对称累计弧长。方向分解为次级候选，累计面积保留为解释与对照，不因相关性高就加入本轮。

## 审计要求

启动前保存源码、配置、数据的 SHA-256。服务器完成后核对完整代数、评估数、配对初始化、最终选解和全部最终个体；另以两点 Gauss 积分独立复算弧长损失，核对统计结果。保留全部正负结果，不覆盖过去实验。
