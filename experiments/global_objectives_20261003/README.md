## 本轮选择

|编号|辅助目标|选择理由|
|---|---|---|
|G-01|双向累积相对偏差|关注连续频段的系统性偏差；没有窗口、事件数量和惩罚系数|
|G-02|最坏连续频段累积偏差|检验 G-01 同类思路中“最坏区间”是否更有用；单独作为第三目标|
|G-05|复阻抗相对平方误差|作为简单对照，辨别改善是否仅来自幅相相对误差的组合|

每个 Case 运行 baseline 和三个单辅助组；每组 100 seeds（0–99），共 800 次正式运行。没有双辅助组合，G-01 与 G-02 不同时加入同一优化。

G-03 搬移距离与 G-04 相关距离存在零总变化量/零方差的退化定义问题，G-06 缺应用激励依据，G-07 与旧几何指标重叠且需进一步分析尺度，G-08 缺测量协方差，因此暂不纳入本次正式批次。

## 指标计算约定

u=(log10 f−log10 f_min)/(log10 f_max−log10 f_min)，r=Zhat/Ztarget−1。

G-01：C_L(u)=∫₀ᵘr，C_R(u)=∫ᵘ₁r，L=½∫(|C_L|²+|C_R|²)du。

G-02：max_{a≤b}|∫ₐᵇrdu|；离散实现的 a、b 遍历全部原始频率采样位置。它等于累计复残差点集的直径。

G-05：∫|r|²du。

所有积分均用原始 u 网格的梯形求积，不添加频率采样点，不改变主目标的按原采样点平均定义。目标阻抗必须非零；无经验 epsilon 替代。G-01 的 1/2 是两种积分方向的对称平均。数值积分规则属于明确的离散实现，不是拟合调参。

Case I 的已知真参数仅用于生成原协议目标谱；三个辅助指标均只访问目标谱，不读取真参数。

## 复核与恢复

运行前仅做软件/解析公式测试，不以小种群或少代数结果筛选指标。每次正式运行保存初始种群、最终完整种群、每代历史、实际评估数与完成标记。指纹记录代码、配置、网格和依赖版本。调度器不会覆盖已完成或未审查的部分目录。

来源目录与文件 SHA256 见各 Case 的 SOURCE.json。程序复制并替换目标定义，原实验目录和结果保留。

批次在服务器后台持续运行；结束后生成配对统计、全种群重算审计、置信区间、原双主目标前沿比较和完整结果压缩包。对照实验只能证明当前协议和数据下的表现，不能把辅助指标改善等同于两个主目标改善。
