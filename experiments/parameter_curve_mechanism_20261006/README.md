本轮使用解析集总电路计算，不运行优化器，不连接服务器。覆盖五种自设计电路、论文 Case1，以及 Case2 的三组拟合参考解。Case2 参数仅解释所选模型，不能视为实测对象的真实元件值。

入口：`run_study.py`。使用已配置的 Python 和 numpy、matplotlib；现有 scipy 从 `tmp/curve_refinement_deps` 读取，用于载入冻结的旧指标代码。无需安装依赖。

输出：`D:/develop/FEMEIF/output/parameter_curve_mechanism_20261006/`。`REPORT.md` 为中文结果报告；`PARAMETER_GUIDE.md` 为每个参数的变化速查；`index.html` 为图文浏览入口；`data/` 保存逐扰动、逐参数、事件、参考参数、数值收敛与源文件校验；`figures/` 保存科学绘图。页面渲染使用已配置的 markdown 库。

预先固定的分析规则：

- 单参数及组合方向使用乘性扰动 `p'=p*exp(sign*ln(1+level/100)*direction)`；levels 为 0.1、0.3、1、3、10、30。负向为倒数，30 档负向实际约 -23.08%，不是 -30%。方向最大绝对分量为 1；不裁剪优化边界。
- Case2 从既有 100 个 baseline 代表解中选择 WSMSE 最低者；另外在 WSMSE 不超过最低值 1.15 倍的集合中，按消除可交换支路标签后的 log 参数距离进行确定性最远点选择。参考集数量为 3，不代表所有可行拟合。
- 曲线机制统计在等 log 频率积分下计算。频率网格为全频带网格叠加参考及候选的支路谐振局部网格，不按加密点数量平均，避免局部加密改变权重。Case2 密集图仅为模型预测；实测点全部保留，绝不插值成新测量。
- 特征频率用解析端口响应与解析频率导数括区并二分细化。实际端口峰位和内部 LC 频率分别记录。半功率宽度仅在峰两侧、邻接谷点或频带边界内都能找到端点时定义；不能得到端点时记缺失，不补零。
- 一般有限轨迹使用固定参考峰窗口匹配，并保留失配和多峰。整体频移有精确已知对应，因此额外按解析延续位置匹配并核验，同时保存固定窗口结果，区分物理变化与匹配伪影。
- 敏感性用 ln 参数的中心差分。复相对敏感性 J/Z 的实部是 ln 幅值响应，虚部是弧度相位响应。SVD 使用这两部分及等 log 频率积分权重；它是局部诊断，不能独自证明全局可辨识性。
- 指标审查直接复用 2026-10-05 的 I-03、II-01、II-02 与累计弧长实现；在原采样网格（Case1 180 点、Case2 201 点）计算，不与密集积分误差混用。Case2 同时保留相对模型参考与相对实测目标的结果。
- 解析缩放恒等式、电路代码一致性、半步敏感性、关键轨迹加密收敛及 I-03/II-02 常数实平移盲区作为执行中的必需检查。

本轮不根据机制分析直接改动正式优化指标。第一轮完成后，用报告中的具体模式决定下一轮参数区域扩展和优化验证。
