# 基于已完成配对结果的三指标候选

36个配对中，14个配对的两项均值都低于各自的两个单指标。由此形成5个三指标候选，每个候选内部的三种两两组合均满足这个更强的均值条件。
这是一种安排后续实验优先级的探索性筛选，不替代原先“优于baseline”的要求，不是统计显著性判断，也不证明三结合有效。
来源为 RESULTS.md 的已完成比较表；下列最小改善幅度依据表中保留三位小数的百分比，仅用于描述性排序。
最小改善幅度取三个配对、各自两个单指标、两项误差共12个百分比改善中的最小值，检查候选是否依赖极小的均值优势。

|候选|三个指标|最小改善幅度 %|
|---|---|---:|
|I-02 + I-06 + II-01|转折区域覆盖5-of-6＋中文PDF峰谷一致性＋局部特征频移误差|4.138|
|I-06 + II-01 + II-05|中文PDF峰谷一致性＋局部特征频移误差＋95% Hausdorff距离|1.112|
|I-05 + I-06 + II-01|全局转折数量至少4个＋中文PDF峰谷一致性＋局部特征频移误差|0.427|
|I-02 + I-05 + I-06|转折区域覆盖5-of-6＋全局转折数量至少4个＋中文PDF峰谷一致性|0.011|
|I-02 + I-05 + II-01|转折区域覆盖5-of-6＋全局转折数量至少4个＋局部特征频移误差|0.011|

优先候选：I-02＋I-06＋II-01。下一步先对它的三个配对相对单指标的配对seed差值做稳定性诊断，再决定是否安排三结合实验。
所有候选仍来自同一批seed 0–99的筛选，最终结论需要新seed验证。之前的八组独立验证不覆盖这些新三结合。
本分析只读取已完成报告，没有启动优化实验或修改任何指标。
