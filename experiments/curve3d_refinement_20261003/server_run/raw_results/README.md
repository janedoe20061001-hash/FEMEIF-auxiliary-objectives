# 第三轮：两项候选的有理由改进与新随机种子复核

## 先回答“够了吗”

不够定稿。第二轮仅 D-05-LP 在 Case II 的幅值主误差上有修正后统计支持，其余改善尚不明确。两个候选只有跨 Case 的均值方向一致。继续添加很多无针对性的指标，会增加事后挑选风险。本轮只检验能从原公式直接指出的缺陷，不保证修改必定有效。

|改动|原公式的问题|本轮怎样检验|仍然存在的问题|
|---|---|---|---|
|R-03-C 全过程累计有向面积|只看最后一个面积，前面与后面的正负变化可能抵消|比较从最低频率走到每个频率时积累的全部面积，并全频段积分|仍不能唯一决定曲线；以起点为锚，噪声会向后传播|
|R-05-C 保留总长度的累计弧长|各自把总弧长归一化为 1，丢失总长度；某段偏差会改变后面的对应|在同一频率比较已经走过的实际长度，共用目标总长度为尺度|弧长看快慢而不看方向，也不看整体平移；不是严格包含旧公式信息的升级|
|R-03-S / R-05-S 标准差尺度|最大最小值决定尺度，极端点可能压缩其他频段|只换成目标曲线全频段标准差，原面积／弧长公式不变|标准差仍受极端点影响，不是稳健统计；各轴等标准差仍是建模约定|

R-03-C 与 R-05-C 沿用原范围坐标；两个 S 变体只修改坐标尺度。**不把不同改动叠加，不设转折事件数量、阈值、窗口、拟合权重或重采样点数。** 主目标始终保留。

## 公用记号与原版对照

目标为 $Z_i^*$，模型为 $\widehat Z_i$，$i=1,\dots,N$；$m_i(Z)=20\log_{10}|Z_i|$，$\phi_i(Z)=\arg Z_i$，相位单位为弧度且保持原主值约定。

$$u_i=\frac{\log_{10}f_i-\log_{10}f_1}{\log_{10}f_N-\log_{10}f_1},\quad h_i=u_{i+1}-u_i,\quad x_i(Z)=(m_i(Z),\phi_i(Z)).$$

原范围坐标（LP）：

$$a_k=\min_i x_{i,k}^*,\quad b_k=\max_i x_{i,k}^*-a_k,\quad p_i(Z)=\left(u_i,\frac{x_{i,1}(Z)-a_1}{b_1},\frac{x_{i,2}(Z)-a_2}{b_2}\right).$$

所有曲线均按原始频率结点分段线性插值，目标与候选共用固定尺度，候选不裁剪、不单独归一化。

原 D-03-LP：$r_i=p_i-p_1$，

$$A(Z)=\frac12\sum_{i=1}^{N-1}r_i\times r_{i+1},\qquad L_{03}=\|A(\widehat Z)-A(Z^*)\|_2.$$

原 D-05-LP：$\ell_i=\|p_{i+1}-p_i\|_2$，$B_k=\sum_{i<k}\ell_i$，$s_k=B_k/B_N$；$\gamma_Z(s_k)=p_k(Z)$ 并分段线性插值，

$$L_{05}=\int_0^1\|\gamma_{\widehat Z}(s)-\gamma_{Z^*}(s)\|_2^2\,ds.$$

取两条曲线全部 $s_k$ 的并集精确积分，不规定重采样点数量。这两个原公式作为本轮不修改的对照。

## R-03-C：不用终点面积代替全过程

$$A_1(Z)=0,\qquad A_k(Z)=\frac12\sum_{i=1}^{k-1}(p_i-p_1)\times(p_{i+1}-p_1).$$

$A_k$ 是走到第 $k$ 个频率时积累的三平面有向面积；三分量来自三维空间的三个坐标平面，并非挑选三个事件。每段内部 $A(u)$ 恰好线性。令 $e_k=A_k(\widehat Z)-A_k(Z^*)$，

$$L_{03C}=\left[\int_0^1\|A_{\widehat Z}(u)-A_{Z^*}(u)\|_2^2du\right]^{1/2}
=\left[\sum_{i=1}^{N-1}\frac{h_i}{3}\left(\|e_i\|^2+e_i^\top e_{i+1}+\|e_{i+1}\|^2\right)\right]^{1/2}.$$

最后面积相同，不再能把中途不同的面积积累直接抵消掉；但若全过程面积本来就不区分两条路径，本指标仍分不出来。

有向面积与路径签名的几何关系参考 [Chevyrev 与 Kormilitzin 的原始教程](https://arxiv.org/abs/1603.03788)。这里只用面积过程，并非完整路径签名；用于阻抗优化的损失是本项目适配，不声称论文验证过本实验。

## R-05-C：不用各自归一化隐藏总长度

$$B_1(Z)=0,\qquad B_k(Z)=\sum_{i=1}^{k-1}\|p_{i+1}(Z)-p_i(Z)\|_2,\quad T^*=B_N(Z^*).$$

$B_k$ 是曲线到同一频率已经走过的实际三维长度；$T^*$ 为目标全长。因频率严格递增，三维曲线长度正，不需要加稳定常数。

令 $d_k=[B_k(\widehat Z)-B_k(Z^*)]/T^*$，

$$L_{05C}=\left[\int_0^1\left(\frac{B_{\widehat Z}(u)-B_{Z^*}(u)}{T^*}\right)^2du\right]^{1/2}
=\left[\sum_{i=1}^{N-1}\frac{h_i}{3}(d_i^2+d_id_{i+1}+d_{i+1}^2)\right]^{1/2}.$$

同时比较全长和长度沿频率的积累顺序，没有候选自己的长度归一化，没有频率扭曲。形状分析中参数化与点对应的区分可参考 [SRV 方法原始论文](https://pubmed.ncbi.nlm.nih.gov/20921581/)。本变体不是弹性形状距离，也没有求解旋转或配准。

## R-03-S / R-05-S：尺度修改单独做对照

$x_k^*(u)$ 为目标的幅值／相位分段线性曲线：

$$\mu_k=\int_0^1x_k^*(u)du=\sum_i\frac{h_i}{2}(x_{i,k}^*+x_{i+1,k}^*),$$

令 $c_{i,k}=x_{i,k}^*-\mu_k$，

$$\sigma_k^2=\int_0^1[x_k^*(u)-\mu_k]^2du
=\sum_i\frac{h_i}{3}(c_{i,k}^2+c_{i,k}c_{i+1,k}+c_{i+1,k}^2),$$

$$p_i^{S}(Z)=\left(u_i,\frac{m_i(Z)-\mu_1}{\sigma_1},\frac{\phi_i(Z)-\mu_2}{\sigma_2}\right).$$

把 $p^S$ 分别代入**原** $L_{03}$、$L_{05}$，得到 R-03-S、R-05-S，不同时修改为累计面积或累计弧长。这使“尺度是否影响结果”与“公式是否影响结果”分开。

这里的标准差针对归一化对数频率的连续曲线，不是任意窗口估计。若目标某轴无变化，应显式说明退化，本实现报错，不添加任意 $\epsilon$。范围与标准差都不能证明三个轴物理重要性相等；本轮只做尺度敏感性检验。

## 冻结的正式实验方案

- 每 Case：基线 + 两个原指标 + 四个变体，每组 100 个配对种子 **100–199**；共 1,400 次完整运行，73,500,000 次评估。
- Case I：原 180 频点、18 参数电路、种群 200 × 300 代；Case II：原 201 测量点、15 参数电路、种群 150 × 300 代。
- 原上下界、初始化方法、NSGA-II 算子、两个主目标、固定 WSMSE 权重及最后一代选同一个体的方法保持不变。没有小规模拟合试验。
- 四个变体分别与同种子基线及对应原指标比较；原指标也与本轮基线比较。不能仅见“相对基线下降”就称优化优于原版。
- 10,000 次配对 seed 重采样给出均值比例下降的 95% 区间；双侧配对 Wilcoxon。全部 24 项对基线比较和 16 项对原版比较合并 **40 项 Holm 修正**。区间不做同时覆盖校正，不声称零差异证明等效。
- 正式运行前软件验证包括零误差、原版公式与旧代码逐元素一致、面积抵消反例、长度信息反例及独立积分核对；不根据拟合效果改定义。
- 新种子用于检查随机优化效果是否重复，**不是新测量数据独立验证**。本轮仍是根据前两轮筛选后进行的探索；禁止跨轮挑最好的百分比汇报。

Case II 的 16 MHz／107° 原点与正参数被动网络存在可行域不匹配。本轮仍保留全部原数据、不改相位、不删除该点，不将其擅自认定为测量错误，也不把它当作所有负结果的解释。
