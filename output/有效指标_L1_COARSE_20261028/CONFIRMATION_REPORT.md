# L1_COARSE：冻结确认通过

在已知六个并联RLC模块串联、无噪声、六个互异可观测模态的理论电路类中，找到了达到既定标准的组合辅助指标。新确认P3为7/8、8/8、8/8，严格峰140/144，20/24代表六峰全过；不能外推任意电路、实测或每个seed保证成功。

## 方法与公平性

粗项为观测等价R/C/L对数坐标的L1距离，精项为按目标相对线宽归一化的逐模态L2距离。每通道内部联合配对全部坐标，强制使用全部可用模态，缺失罚来自原盒上界。定义与孤立模块容差关系见[MATH.md](MATH.md)。指标只用观测极点、留数、已知拓扑和原边界，不以真元件或P3编号打分。

开发阶段L1_COARSE为7/8、8/8，按冻结排序优于其他候选后，先冻结方法及源文件，再由未用rng862032一次生成三个新参数条件、使用新seed74000—74007。没有重抽目标、改权重、放宽门槛或重跑到通过。四组同seed、初始化、边界、算子、200×300、每次60000候选，共96项576万主搜索评价；最终仍取冻结MAG/PHA二维膝点。12项24次短程为部署验证，不参与统计或重新初始化。
