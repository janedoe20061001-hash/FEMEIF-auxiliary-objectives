# 已通过新参数确认：L1_COARSE

观测等价元件的L1粗距离，加上线宽归一化的逐模态L2精距离。使用观测极点、留数与原参数盒，不读取目标真元件。仅支持已知的六个并联RLC模块串联、六个互异可观测模态的理论电路类。

三个事前冻结的新参数条件，P3为7/8、8/8、8/8，严格峰140/144；GLOBAL_Q为0/24、35/144。幅相与参数收益、数值、成本、独立审核均通过原冻结标准。9709份原始文件已完整恢复并逐一通过SHA256，最终验收见[FINAL_ACCEPTANCE.json](FINAL_ACCEPTANCE.json)。

- [独立实现](observable_axis.py)：NumPy、SciPy，无项目原生库依赖。选择 `method='L1_COARSE'`；源码中其他方法只是开发比较分支，未作本次新确认。
- [定义、物理解释及限制](MATH.md)。
- [观测输入示例](observed_target.json)不含真元件；[候选示例](example_candidate.json)来自第一组、第一预定种子的冻结幅相膝点。

运行 `python example.py` 只重放代表的两个辅助值，不重新优化。候选数组每行为 `log10(R,L,C)`，支路行可置换；参数必须在提供的原盒内。辅助值仍与原MAG/PHA主目标配合，最终代表仍按原二维膝点选取。跨平台重放使用原独立数值容差；固定Linux版本的全部冻结最终分数另有更严格核对。
