# 本轮问题、处理及影响

2026-10-11。原优化252条代表未修改；本轮没有新搜索。

|问题|怎样处理|对结论的影响|
|---|---|---|
|补充程序第一次启动导入了错误的通用run模块，缺少simple函数|保留首次脚本和记录；按本地绝对路径显式加载唯一模块|第一次没有完成补充结果；不使用其结果，未修改科学输入|
|第二次提取中，某个采样相位极值的相邻点未包住解析导数零点|严格检查中止并保存第二次脚本；改为先找解析导数的真实符号穿越，再计算精化极值序列的突出程度；全批重算|保留5°显著性门槛、两级稳定门槛及原事件标准，没有为了通过检查改变容差|
|整体尺度的原倍率为2的整数幂，浮点残差恰好为零|独立用0.7与1.3验证七个目标，共14项节点法检查|最大相对误差约8×10⁻¹²；支持解析尺度关系，不把整倍数零残差当作统计发现|
|过零状态的粗门槛没有标记许多原相位事件失败|另外检查≥5°相位峰谷，原诊断完整保留|说明过零特征的覆盖有限；不以新检查更换原成功标准，不把27/37当作准确率|
|相位峰谷补充来自第一轮结果后的观察|使用单独的SUPPLEMENT_PROTOCOL.md、状态及输出，注明探索时序|不是预注册的独立预测，也没有证明优化增益|
|固定区域内“未匹配”可能是错位或显著性不足|保留频率、区域、原始极值和额外事件明细|不声称该结构在整条候选曲线上绝对不存在|
|事件门槛及全局频率容差对极窄结构可能过粗|报告连续误差及目标局部角度切线尺度；原门槛不改|不因原门槛通过就宣称精确恢复；切线尺度不冒充实际有限频移的相位误差|
