# JOINT_POWER定义与物理范围

本指标在原MAG/PHA两主目标外增加两个辅助目标，描述已知串联六模块并联RLC理论类中的模态错位、宽度、功率面积及等效元件误差。它组合已有物理坐标，没有增加目标信息或提出新物理定律。是否有效必须由冻结对照试验证明。

## 观测量

输入为正频复阻抗极点p及对应留数a，频率单位Hz，留数单位Ω·Hz。令ν=|p|、γ=Im p、w=γ/ν、k=Re p/γ，并取完整共轭极点对在ν处的贡献：

    B = a/(ν−p) − conj(a)/(ν+conj(p))

在已知孤立并联RLC模块中，B=R，ν=1/(2π√LC)，γ=1/(4πRC)。由观测模态可得等效C=1/(4π|B|γ)、L=|B|γ/(πν²)。这不是一般网络内部元件唯一辨识的结论。

以x=ln(f/ν)为横坐标，孤立模块满足

    |Z(ν exp x)|² = R²/[1+sinh²(x)/w²]

令t=tanh x，积分密度变为R²/(1+k²t²)，因此

    A = ∫|Z|²dln f = 2|B|² atan(k)/k
    F(x) = 1/2 + atan(k tanh x)/(2atan k)
    h = 0.5 ln(1+2w)

三个四分位位置为lnν−h、lnν、lnν+h。A量纲Ω²，是模态功率增益面积，不是焦耳储能；也不是完整多模块端口响应的面积，后者包含叠加交叉项。目标B有复误差时，面积与宽度定义为|B|的标准RLC包络，方向误差另计。真正功率解释仍限已声明RLC类。

## 同一模态配对内的联合成本

下标t和c分别表示目标及候选，定义

    u = ln(νc/νt),  g = ln(γc/γt),  b = ln|Bc/Bt|
    ec = −g−b = ln(Cc/Ct)
    el = g+b−2u = ln(Lc/Lt)
    η = ln(hc/ht),  e = ln(Ac/At)
    d = |Bc/|Bc| − Bt/|Bt||

JOINT_POWER的两个配对成本为

    C = |u|+|η|+|e|+|ec|+|el|+d
    D = sqrt[b²+(ec²+el²)/wt²+d²]

粗项共同支付位置、宽度、面积和C/L偏差；精项沿用经验证的线宽归一化元件距离，给窄峰相关物理失真足够代价。所有权重在开发前固定为1，没有对本次确认目标调参。

这不是旧L1_COARSE粗项|b|+|ec|+|el|+d乘常数：固定ν、γ而改变|B|时，新旧粗项比值为4/3；固定B、w而同比例改变ν、γ时，比值为3/2。它改变了失真方向的相对代价，并未创造新的可观测信息。新组合可能改善某些条件，也可能增加曲线或参数误差；应完整比较强对照L1。

两个通道各自进行完整Hungarian匹配，再对目标模态数取均值。每个通道的所有成本项先在同一模态对内加总，不能为面积、宽度和元件分别挑不同配对。两个通道自身的最佳完整配对可以不同，这与原多目标定义一致。最终代表仍由MAG/PHA二维膝点选取，辅助最小值不能决定代表。

## 缺失及盒界

可用振荡模态全部匹配；完全相同极点先合并留数；真实非振荡模块不伪装成振荡模态。候选少于目标时，仅补必要缺失列，每缺失另加Dmissing=nextafter(Σ目标行上界+1,+∞)，无自由丢弃模态。 精确通道总分为Σ实际配对成本/n+(n−m)Dmissing，其中n为目标模态数、m为候选可用模态数；缺失罚不再除以n。

原R/L/C盒给出ν上下界及w下界；h∈[0.5ln(1+2wmin),ln3/2]。同极点合并时R为各R之和、C为倒数和的倒数、L为各L之和，因此以Rmax乘模块数、Cmin除模块数、Lmax乘模块数包住合并情况。A下界为Rmin²·2atan(kmin)/kmin，上界为2(nRmax)²。粗项行界为各对数误差上界相加及方向界2；精项行界由平方项上界构造。原代码、70位独立矩阵及压力控制共同验证这些界。

## 参数关系、误差及范围

在本已知可辨识类，ν、h、A可恢复w=(exp(2h)−1)/2、γ=wν及R=√[Ak/(2atan k)]，再得到C/L。事后参数误差按支路置换匹配，真元件不参与辅助适应度。一般网络、重合模态、有限精度可观测性、噪声或实测不能由此获得相同保证。

首次未用目标的双精度AAA准入失败完整保留。观测数值修复只把实际元件模拟响应及局部频率映射改为70位求值，再舍入为complex128观测样本；原AAA和所有阈值不变。三个原抽样目标、指标公式和seed均未重选。70/90位观测一致，且与原双精度物理响应相差约1e-12。主目标训练保持原实现，对全部方法相同。确认结论若通过，也只支持声明分布中的精确无噪声、互异可观测六模块RLC理论类及准确观测，不支持任意电路或噪声实测。
