# JOINT_POWER

元件坐标与模态功率面积的联合辅助指标。见[确认报告](REPORT.md)、[定义与物理范围](MATH.md)及[最终验收证书](FINAL_ACCEPTANCE.json)。

安装NumPy、SciPy后运行 `python verify_replay.py`，复放24个冻结代表及支路置换。`observed_targets.json`只有观测极点/留数与原盒，未提供目标真元件；`ObservablePower(..., method='JOINT_POWER')`输入6×3的log10[R,L,C]返回两个辅助目标。完整优化和严格曲线判决是独立冻结证据，重放脚本不重选代表。

结论限准确无噪声的已知六模块RLC理论类及声明分布；原双精度观测准入失败已保留，高精度修复使用同一抽样条件。

本包验收方法仅JOINT_POWER。冻结代码保留另外两个开发组合供复现失败，未将其认定为已验收方法。
