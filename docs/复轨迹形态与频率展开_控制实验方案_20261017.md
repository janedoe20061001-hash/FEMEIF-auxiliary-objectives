# 复轨迹形态与频率展开：受控实验方案

日期：2026-10-17。先冻结本方案、数据与实现，后计算结果。仅进行本地诊断实验，不启动优化或服务器任务。

## 问题及假设

严格移频签名不能处理一般形变。本轮不放宽它的数值容差，而检验一种拆分表示：在固定目标阻抗半径内，分别记录有序复状态轨迹、轨迹总长度和频率展开。它不自动证明候选与目标属于同一内部物理模式。

对简单串联RLC和既有notch电路，改变Q可保持一定区间内的有序复路径而改变频率展开。纯移频应保持形态与展开宽度，频率位置应单独变化。串联电阻偏置应改变复状态，不能被自归一化消除。附加支路可能引入额外过程，须保留全部谷及内部峰谷序列。

## 固定定义

使用x=log10(f)。目标谷的绝对边界半径为h=|Z_target(x_center)|×10^(3/20)。搜索范围仍为目标中心±4个原目标核心宽度W，目标尺度S不变。

枚举所有严格径向谷。对每个谷，若谷底幅值小于h，在左右分别寻找最近的|Z|=h横截点。缺一侧、谷底超过半径或没有谷时，明确返回无法构成此段。横截段内的额外极值完整保存，不能因为找到两端就判为孤立完整谷。横截点可能仍连接到背景，本轮会把这一风险作为检验对象。

在该段按归一化累计弧长u∈[0,1]取257点，保存Z(u)和x(u)，不平移、旋转或缩放候选复状态。与同法提取的目标并列比较：

1. G=max|Z(u)-Z_target(u)|/S：有序复状态差；
2. L/L_target：未经候选自身幅度归一化的总路径量；
3. Δx/W：谷中心频移；
4. P=max|[x(u)-x_center]-[x_target(u)-x_target_center]|/W：去中心后的频率展开差；
5. B/B_target：两绝对半径横截点间的频宽比；
6. 内部极值类型与数量、谷底Re/Im、是否为单谷无额外峰。

归一化弧长u只是对应的参数化；L与实际频率必须并列，不能把G小解释为宽度或位置恢复。本轮不设结构合格阈值、不合并总分、不重新标记旧样本、不用最低G强行选谷。

## 数据与独立核验

沿用五个既有理论目标。每目标：基准1、纯频移4档(−1.4,−0.65,0.65,1.4)W、电阻偏置4档(0.075,0.2,0.4,0.8)S、附加并联RLC串联支路12档(幅值0.2/0.8S，位置−0.17/0/0.17W，宽度0.025/0.12W)、背景1；合计110项。三个简单目标各增加Q变化4档(0.3,0.6,1.7,3.3)及Q与移频组合4档，合计24项。新构造共134项，另分析旧32个候选，共166项。设置为相关机制开发数据，不是独立推广。

匹配提取函数仅接收模型和目标，已知操作类型及参数仅用于事后控制核验。基准、移频及简单Q变化/组合共49项应满足有序状态与路径量不变。Q对应的横截宽度可由解析关系独立计算：以目标半宽d计，B_new=2 asinh(sinh(ln(10)d)/k)/ln(10)。串联RLC和notch本轮的Q参数变化均适用此关系。移频中心有解析真值，组合同时验证频移与宽度。

新134项均核对独立节点响应；有解析物理恒等式的设置另行点值验证，偏置/附加支路验证响应相加。误差不通过原样保留。

## 数值门槛与停止规则

模态锚点细分128/256，必要时512/1024。根及横截点位置差≤10^-9 decade，候选数量、段状态及内部极值序列相同；归一化状态曲线差≤10^-4+10^-3×较细曲线尺度，路程/频率展开差使用同类绝对及相对数值门槛。路径长度与独立Gauss64积分核对(10^-4 S+10^-3 L)。

49项恒等几何控制以G≤0.003、|L/L_target−1|≤0.003核验表示误差；中心位置≤10^-9 decade，已知频宽比例误差≤10^-6。这些是受控恒等式的数值核验门槛，不是允许一般形变的结构接受线。不得为通过而放宽。

若对附加过程出现形态差和频率差同时很小的非平凡例子，必须公开该反例，不能宣称实现了普遍归属。即使所有控制通过，也只能支持这种拆分表示在本批的可解释性，不能称其已改善优化或优于ARX/JV。
