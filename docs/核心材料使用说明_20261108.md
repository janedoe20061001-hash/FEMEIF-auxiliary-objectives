# 下载后的使用与复核

## 三个层级

1. **理解结论**：从[研究现状](研究现状_20261108.md)和[下一步](下一步_20261108.md)开始。
2. **复算核心结果**：读取三批逐seed CSV重新汇总，并通过便携API重算72个固定代表的两个辅助值和支路置换。
3. **完整重跑研究**：还需要原优化环境、模态提取流程、模型/算子、全量原始种群及运行输入。本次精选增量不提供一键完整重跑承诺。

## 文件怎么对应

| 目录或文件 | 用途 |
|---|---|
| `output/有效指标_L1_COARSE_20261028/` | 原批定义、独立API、3个观测目标、24个固定代表、确认全表 |
| `output/L1_COARSE_扩大参数验证_20261028/` | 同公式的更宽参数确认及另24个固定代表 |
| `output/有效指标_JOINT_POWER_20261028/` | 变体定义、独立API、同批五组比较及另24个固定代表 |
| 各目录 `evidence/PER_SEED.csv`、`EVENTS.csv` | 全部方法的逐次主误差、结构判决、参数误差、CPU和逐峰记录 |
| `STRICT_FAILURES.*`、`STRICT_SELECTED.json` | 失败与冻结严格判决，防止只保留好看的代表 |
| `COST.json`、`PRECHECK.json`、`OBSERVATION_ONLY_AUDIT.json` | 历史成本、数值前检及信息隔离证据 |
| `FINAL_ACCEPTANCE.json` | 原范围实验验收，**不是创新性认证或本次全部重算证明** |
| 各目录 `figures/` | 三条件全部8seed代表，包含失败，不以平均曲线隐藏波动 |

科学实现、CSV、JSON、图保持原字节；Markdown阅读副本增加日期说明并修复链接。未附带的原报告引用明确指向[本地保留清单](../archive/CORE_LOCAL_ONLY_20261108.md)。历史JSON中的路径与SHA描述其原环境，不能假设所有被引用文件都已经上传。

## 推荐复核命令

在仓库根目录，使用Python 3.12独立环境。辅助API所用版本是NumPy 2.2.6、SciPy 1.15.3；完整旧优化还使用其他依赖，本命令不运行优化。

```sh
python -m venv .venv
# 激活环境；Windows PowerShell 用 .venv/Scripts/Activate.ps1
# macOS/Linux 用 source .venv/bin/activate
python -m pip install -r archive/core-requirements.txt
python archive/verify_core_20261108.py
python archive/verify_snapshot.py
```

`verify_core_20261108.py`在临时目录使用核心实现，只读检查发布文件、从CSV核对3批312项确认记录的摘要，并重算72个固定代表及72个支路置换；不改原记录。它**不**重新提取模态、不重新优化、不重新积分判定曲线结构，也不复现历史CPU。原包中的`verify_replay.py`会写入本目录`LOCAL_REPLAY.json`，若直接使用请在副本运行。

`verify_snapshot.py`只需Python标准库，检查整个仓库当前清单的文件哈希及Markdown本地链接。检查成功说明发布材料完整，不自动证明每个科学结论正确。

## 最小调用

L1的`example.py`可运行一个固定代表；它故意保留首seed的P3失败，没有另挑成功例子。候选输入为6×3的`log10(R,L,C)`，目标输入为Hz单位极点、Ω·Hz单位留数及原边界。输出是两个辅助值，仍应与原MAG/PHA两个主目标一起使用；不能以辅助最小值替换原最终选解。

现有输入已经提取好模态；任意CSV、含噪测量或一般电路需要另做观测与适用性审查。参数解释只对声明的已知可辨识类成立。
