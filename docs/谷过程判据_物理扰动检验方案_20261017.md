# 谷过程判据的物理扰动检验：冻结方案

日期：2026年10月17日。范围：理想无噪声电路的本地机制实验，不运行优化，不修改既有指标或事件标签，不从结果选择新阈值。

## 1. 要检验什么

上一轮32条旧候选说明，点位置、高度、3 dB宽度达标不保证完整复轨迹过程恢复。本轮用新生成、与旧候选不同的物理参数，检查五类连续诊断能否响应已知操作：绝对复状态、频率位置/顺序、弧长总量、沿频率累计弧长分布、切向及附加往返。没有预设一种诊断独立解决所有问题。

## 2. 五个目标

1. 已有混合网络原条件和LC条件，仍属于开发目标。
2. 串联RLC：R=25 Ω，f0=25 kHz，Q=10，L=QR/ω0、C=1/(ω0QR)。
3. 两个陷波参照：Z=Rs+Rp//(Rm+L+C)，Rs=5 Ω、Rp=200 Ω、Rm=20 Ω、f0=25 kHz，Q分别20和2000。L=(Rp+Rm)Q/ω0，C=1/((Rp+Rm)Qω0)。这里Q是声明的支路频率尺度，不等于通用端口品质因数。

简单电路的核心区由目标谷底上升3 dB的连续交点确定；原混合网络保留旧V3核心区与窗口。简单模型的外窗口取核心总宽度的左右各4倍。坐标为log10 f，阻抗尺度来自目标。候选在相同绝对频率比较，不对齐、不自行缩放。

串联RLC的复平面路径为直线；陷波参照改变Q时保留完整复平面路径、改变沿频率的推进。这两种参照刻意检验几何诊断的边界，不能强制任何谷有圆环。

## 3. 预定266个设置

|操作|参数|数量|
|---|---|---|
|目标原值|5目标|5|
|整体移频|全部L、C同时除以s，log10 s为目标核心宽度的±0.25、±0.5、±1、±2|40|
|实部偏置|增加串联电阻，增量为目标谷底幅值的0.05、0.1、0.25、0.5倍|20|
|简单RLC的Q操作|L乘k、C除以k，k=0.125、0.25、0.5、1.5、2、4、8|21|
|附加窄并联RLC串入端口|峰阻抗为目标谷底幅值0.1、0.5、1倍；中心偏移为核心宽度−0.1、0、+0.1；其对数半功率宽度为核心宽度0.01、0.05、0.2倍|135|
|仅背景参照|取目标中心ReZ作电阻，正ImZ用串联电感匹配；若目标中心ImZ为零，用纯电阻|5|

|简单模型组合操作|移频±1核心宽、串联偏置0.1或0.5、Q因子0.5或4的全组合|24|

附加支路全部为正R/L/C，并保留具体参数。极窄理想支路可能需要不适合真实器件的参数，仅作无噪声压力测试，不声称可直接制造。加入支路不保证幅值极值计数一定增加，不能将没有新极值当作没有改变。

## 4. 不依赖旧标签的参照关系

- 移频应满足Znew(f·s)=Ztarget(f)；全频轨迹相同，但固定窗口可能截断结构。
- 串联电阻偏置应满足Znew−Ztarget=ΔR，导数不变。弧长和归一化弧长分布应不变，而复状态误差增大；幅值谷位置可能随之改变。
- 陷波Q操作有精确重参数关系：若u=ln(f/f0)，则uc=asinh(sinh(u)/k)，对应点复阻抗相同。串联RLC则在相同频率满足Xnew=kXtarget；其归一化弧长分布可能完全不变，不能预设它能独立表示所有“变窄”。
- 附加支路的Z差等于独立支路响应；检查总量、分布、状态和极值顺序实际如何变化，不强制每档产生一个环。
- 背景参照没有严格径向谷；纯电阻弧长为零，累计弧长比例和切向方向应记录为不适用，不强行赋0或1。
- 混合网络R1/R3操作会耦合改变位置、高度与展开，仅作实际网络检查，不当作纯Q操作。

## 5. 检查和决策

主输出是连续量及解析关系，不生成“完整恢复”的新合格率，不拟合权重，不将新候选当独立方法推广。原混合目标已参与开发；简单电路是机制参照。若诊断有盲区，保留反例并缩小其适用范围。

固定核心区和外窗口分别计算：三个目标频率的复状态/切向、径向极值根及顺序、总弧长、端点位移效率、10/50/90%弧长频率位置及分布差。分布按候选自身弧长归一化，仅用于诊断，必须与总量并列；位置、幅度与窗口截断分别报告。

模态锚点折线128/256，必要时512/1024；绝对10^-4、相对10^-3检查弧长与分布，根数/类型必须一致、根位置差≤10^-9 decade。弧长独立32/64阶Gauss复核，必要时加密分段。关系核对容差为10^-8 Ω+10^-7相对，保留实际偏差；节点电路抽样用旧独立核验门槛及70位回退。零弧长数值保护为10^-12倍目标中心阻抗尺度，不作为结构成功门槛。

所有设置、源文件和输入哈希在新响应计算前冻结；每个失败保留，不能通过改参数、删除档位或放宽门槛修复。产出正式报告、全表、四类扰动代表图、盲区及下一阶段评价定义建议。不连接服务器、不上传网站、不创建监控。
