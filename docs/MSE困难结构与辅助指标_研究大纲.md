## 一、我们距离最初的目标还有多远？

最初想解决的是：**阻抗曲线中，哪些结构用幅值、相位MSE很难拟合好？为什么？能否设计一个指标帮助程序把这些结构做好？**

目前已经完成了“发现问题线索”和一部分“排除检查错误”。我们看见了漏峰、峰谷宽度偏差和局部相位转变偏差，也知道采样遗漏、模型能力限制和选解规则会影响判断。

但我们还没有完成两件核心工作：

1. 把“某张图没有拟合好”变成“某类结构在规定条件下反复难以拟合”的证据。
2. 用对照实验证明，一个针对该结构的辅助指标确实改善了结果，并且代价可接受。

因此，研究已经有了明确线索，距离最终结论仍有关键实验。下面收拢成**五步**：前三步争取得到第一个有依据的指标，后两步检查它是否经得起换电路和真实数据的考验。

不宜报一个完成百分比或固定天数。第一步的结果可能表明某个问题主要来自采样或搜索预算，那就应当调整方向，而不是为了做指标把它强行归为MSE缺陷。

## 二、先把“MSE无法优化”说准确

Case1由正确电路生成，真参数也在搜索范围内。在这些参数处，幅值和相位误差可以同时为零。因此，它不能用来证明“MSE在理论上不可能拟合正确结构”。

我们更适合研究的是：

> 在模型能做到、采样足够可靠的条件下，使用规定的算法和计算预算，MAG/PHA是否仍经常难以恢复某些结构？加入辅助指标是否能更可靠或更快地恢复它们？

“难”至少要附上电路、参数范围、采样、算法、预算和选解规则。这是可检验的研究问题，也与实际使用更接近。

另外，MSE是打分方法，优化器是寻找参数的方法。没有找到好解，可能是分数提供的引导不足，也可能是搜索还没找到合适参数；目前不能把所有失败都归到MSE上。

## 三、五步研究路线

### 第一步：确定真正值得研究的困难结构

**要回答：反复没有做好的东西，具体长什么样？排除明显干扰后，它还存在吗？**

先围绕已有Case1结果，暂时只保留两类重点候选：

- 目标有窄峰或窄谷，拟合出现漏失、明显变宽或移位。
- 幅值已比较接近，但对应的局部相位变化仍缺失、位置偏离或过于平缓。

这两类目前是待确认的候选，不是已经证明的普遍规律。优先挑最有重复证据的一类深入，不同时为所有缺陷设计指标。

具体做四件事：

1. 给已有100个seed的阶段结果做统一分类：位置、宽度、明显程度，以及这种缺陷在多少个seed、哪些阶段仍存在。用少量典型图展示真实曲线，不平均曲线。
2. 检查双目标前沿：是否已经有恢复该结构的解，只是画图选解规则没有选中？若是，应先解释幅相取舍和选解影响。
3. 在Case1上补一个可靠采样的MAG/PHA训练基线。已有自适应诊断只是证明这批曲线能被看清楚，尚未证明训练时使用它会改善结果。
4. 在同一可靠评价设置下比较短预算和延长预算，例如300代与1000代，查看缺陷是否仍频繁存在。开始前冻结配置；不反复延长直到得到想要的答案。

新增频点要保持明确的频率权重，不能因为局部点数增加，就无意中改变这段的重要性。记录候选评价次数与实际频率计算量，不把“同代数”写成“同计算成本”。

**这一步的交付：一张困难结构清单。** 每类附典型曲线、出现频率、随代数变化，以及采样、预算和选解能解释多少。

如果缺陷在可靠采样或延长预算后明显消失，就把它归为对应的评价或搜索问题。若仍存在，就进入第二步。不能提前承诺最后一定找到某一种MSE困难结构。

### 第二步：找出“什么情况下更难”，把现象变成规律

**要回答：是峰太窄、峰谷太近、局部变化不明显，还是幅值和相位存在取舍？**

这时使用有控制的理论电路，而不是只收集更多随机曲线。

例如，研究窄峰时，用参数成对调整，让峰位置和高度尽量保持一致，逐渐改变宽度，观察失败率是否随之变化。若无法保持其他特征一致，就记录它们的联动，不能把变化全部归因于宽度。

研究相邻结构时，逐渐改变峰谷之间的距离；研究相位困难时，比较幅值误差接近的候选，看相位变化是否仍有很大差别。

先利用现有电路库筛出成组的可比目标；开发阶段用较少seed定位趋势，再对关键条件增加seed确认。只选几个好看的例子不足以得出规律。

同时检查：

- 哪些局部残差在整体MAG/PHA下降时仍持续存在？
- 幅相误差都相近的候选中，有无该结构是否仍差别很大？
- 局部结构的误差在总分中实际占多少，而不是预先断言所有窄峰都被忽略？

**这一步的交付：一个明确、可反驳的困难假设。** 例如：“在已验证的宽度范围内，越窄的峰越常漏失；提高预算后趋势仍存在。”它也可能被实验否定。

这一步仍不能把打分和搜索的原因完全分开，但可以说明为什么某种结构值得单独引导，并限定结论适用范围。

### 第三步：针对一个困难，验证一个辅助指标

**要回答：给程序增加一条针对性的要求，能否修复刚才确认的结构？**

保持MAG/PHA两个基础目标。第一轮只增加一个辅助指标，选法由前两步决定：

| 确认的问题 | 优先验证的方向 |
| --- | --- |
| 目标峰谷经常没有对应结构 | 峰谷存在性或匹配误差 |
| 峰谷存在，但宽度反复不对 | 宽度或局部形状误差 |
| 局部相位变化持续不对 | 局部相位变化或频带误差 |

这张表是候选对应关系，不代表这些指标已经有效。阈值匹配还可能带来不连续、误配和噪声敏感的问题，正式公式需要在困难结构确认后再冻结。

做成对比较：“MAG/PHA”与“MAG/PHA＋一个辅助指标”。使用相同seed、初始化、参数范围和明确的预算口径。

检查辅助指标是否仅改变了取舍位置，还是在相近幅相误差下也能改善结构。保留前沿和预先约定的代表解规则，不能为新方法事后挑最好看的解。

**这一步的交付：第一个指标的有效性结论，可能有效，也可能无效。**

至少同时报告结构改善、MAG/PHA变化、计算成本和seed之间的稳定性。允许的幅相退步范围应提前规定；不能实验结束后才把退步解释成可以接受。

做到这里，就已经正面回答最初的目标：什么结构困难、为什么值得针对它增加引导、增加后是否有帮助。

### 第四步：检查它是否只对开发样本有效

**要回答：换新seed、参数和电路，这个指标还成立吗？**

在第二、三步开发指标前，预留一批不参与调指标的电路和参数；最终使用新seed验证。目标包括出现同类结构的其他拓扑，以及没有该缺陷的对照电路。

检查三件事：同类困难是否仍改善；原本拟合良好的结构是否被拉坏；如果加入噪声或减少测点，指标是否变得不稳定。

若调整指标或权重用到了验证结果，这些样本就已参与开发，不能继续称为未见过的最终验证集。

**这一步的交付：适用条件与失败边界。** 例如，对某范围的可见窄峰有效，对缺乏测点支持的结构无证据，或者噪声较大时容易误配。

这一步才能支持“对一类问题有用”，而不是“对Case1有用”。仍不追求覆盖所有电路。

### 第五步：用真实数据检查实际价值

**要回答：理论上有帮助的指标，到了实测数据还能合理工作吗？**

使用Case2和已准备的公开RLC测量，先建立各自模型的MAG/PHA基线，再验证适用的辅助指标。模型不能表达的部分单独说明，不据此宣布指标失败或成功。

只在原始测点支持的结构上评价拟合改善。对测点之间的预测，可以报告尖峰和不同候选之间的分歧，但没有新测量就不宣称已经还原那里真实的结构。

如果Case2或公开RLC不包含前面确认的困难结构，它们仍可用于检查指标有没有副作用，却不能自动作为该困难的正面验证。

**这一步的交付：实测适用性报告。** 如果真实数据不足以验证某个结构，应明确限制，并据此决定是否值得补测或寻找新的同类数据。

真实数据扩充放在这里深化。它不是完成前三步、提出有证据指标的前置条件。

## 四、后续实验怎样防止继续偏离？

每轮实验开始前，必须能用一句话说明它帮助回答以下哪一个问题：

1. 哪类结构反复难以恢复？
2. 哪个条件使它更难？
3. 针对性指标能否改善它？
4. 改善是否能推广，代价是什么？

对应不上的工作先暂停。具体约束如下：

- 暂停扩大WSMSE、原始距离和对数距离的比较；它们已有结果，当前主线是MAG/PHA。
- 暂停大量爬取与当前模型不相符的数据，现有公开RLC足够支持下一阶段实测准备。
- 采样工作限定为让困难判断可信，完成可靠基线后回到结构研究。
- 不同时加入多个新指标，不无限调权重、改阈值或扩充电路。
- 只展示少量典型曲线；总体判断使用逐seed诊断，不平均曲线。
- 每轮记录“看到什么”“证据支持什么”“还不能说明什么”，用通俗本地Markdown汇报。没有明确发布要求时不上传网站。

## 五、紧接着的一轮应该做什么？

**执行第一步：Case1困难结构归类、前沿检查，以及可靠采样与延长预算的基础目标对照。**

本轮不新增辅助指标，优先输出一份能看图理解的报告：

| 报告内容 | 想让读者得到的答案 |
| --- | --- |
| 2–3类候选困难的典型图 | “难的结构长什么样？” |
| 随阶段变化与100个seed统计 | “是偶尔失败，还是反复发生？” |
| 前沿与选解核查 | “是否已经有好答案，只是选解没选中？” |
| 可靠采样、短/长预算对照 | “看清楚、多找一会儿，还难不难？” |
| 保留或排除理由 | “下一轮究竟值得针对哪一种结构做指标？” |

这份报告才是接下来选择指标的依据。第一步结束后，根据证据进入第二步；若尚无可靠困难结构，就明确报告该结果，不跳过证据直接设计惩罚项。
