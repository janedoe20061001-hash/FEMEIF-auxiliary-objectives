# 寻找阻抗拟合辅助目标：有效进展与证据索引

更新：2026-10-17。范围仅为FEMEIF背景下寻找辅助目标的研究。本文是对既有结果的整理，没有新增优化、修改指标或重选代表解。

## 当前结论

**已经找到有条件的改善线索、可靠的评价实现及明确的失败边界；尚未找到可在不同电路上稳定改善完整结构、且代价已被证明合理的新通用辅助目标。**

目前保留MAG/PHA双主目标。辅助目标的用途，是在有限搜索预算下帮助保留值得继续探索的候选。理论电路真参数在搜索范围内，因此已有失败不能证明“MSE理论上无法拟合”。最终误差、局部结构、搜索过程、代表解选择和计算成本要分别核查。

## 2. 阶段结果及其限制

### 早期局部、全局和累计指标：工作对照已形成

10月5日统一比较在两个Case、六组方法、相同seed与规定预算下完成1200次优化。此前七轮全局/三维探索为8600次完整运行；部分轮次复用seed编号和重跑基线，不能称为8600个独立新随机条件。

累计弧长R-05-C是早期几何方向值得保留的候选。Case2中它与方向＋速度组合没有分出两项主误差都更好的赢家。Case1中累计弧长相对方向＋速度的相位均值改善约25.43%，通过当轮校正，幅值均值反而变差约9.29%，未获得明确差异支持。不能写成共同升级。

T-01与旧累计残差在公式上不同，但没有充分的增量收益。相关性较高也不能作为进入优化的充分条件。历史代表解使用原固定WSMSE选择；不得与后续二维膝点结果直接拼成一张跨轮效果排行榜。

历史的低/中模拟噪声、缺失频点试验仅按各自原协议解释，不能当成新的实测推广。详见[统一总结及原始统计入口](../output/近期研究统一总结_指标演变与验证_20261005.md)。

### 具体困难与T/C/B：有正向证据，也有明确副作用

Case1在提高采样可靠性、延长搜索预算后，仍经常没有完整恢复极窄峰谷组合。它给出了值得研究的具体对象，但没有完全隔离评价、搜索与选解的因果贡献。

第三步三轮共252次优化保留原搜索，用统一二维膝点规则重选并复核代表。最新轮每条件4seed：

|候选及条件|关注结构结果|必须一起保留的限制|
|---|---|---|
|T：角度进程，梯形网络|基础0/4，T为3/4；这3条两项全频误差也改善|仅开发目标，尚无独立推广|
|C：顺序累计，混合支路|基础1/4，C为4/4；3/4两项全频误差不退步|仍有全频幅值或相位结构缺陷|
|B：跨窗连接，三级网络|4/4关注组合通过，4/4两项全频误差改善|每seed均出现一对窗口外额外峰谷，合计8事件|

Case1没有稳定解决。膝点及其回退也可能选择明显不合理的幅相取舍；每个方法各自归一化前沿后的位置，不能用于跨方法比较。现行依据是[重新选解后的报告](../output/mse_structure_step3_knee_20261011/REPORT.md)，而非旧加权选解版本。

### 联合轨迹与ARX：数值可靠性先于效果判断

10月12日联合轨迹开发批为23条件×10组×8seed=1840任务。发现212例辅助训练/复算漂移，其中59例加密不收敛；另有1例事件判定不稳定。Case1新7组有54/56未通过相关复核。这些样本不能继续用于可靠的候选排名。[完整结论](../output/complex_joint_20261012/FINDINGS.md)保留全部失败与通过子集。

10月14日改进积分后的联合面积比较为3条件×8组×8seed=192任务。144个辅助任务全部通过评分复核；192个结果中191个通过全部独立门槛，1个基础样本的结构判定不稳定。

较窄混合条件下，ARX关注幅值事件完整数为12/16，基础为4/16，6/8seed满足预定联合收益约束。但这16次事件检查不是16个独立seed；ARX相对G0/J0/H/A的直接配对探索区间仍跨零。原参数混合条件及Case1未表现出通用优势。

10月15日轻量化把同候选辅助求值加速约4.4倍、20.5倍；正式优化成本仍约为基础的2.2倍和5.1倍。不能把辅助求值加速直接写成整场优化加速。新seed批原ARX在较窄混合条件的完整事件数为10/24，基础9/24，说明前批12/16只是开发线索。新尺度未解决Case1 P3的0/12完整恢复，也未优于各项对照。[轻量化证据与限制](../output/arx_light_20261015/FINDINGS.md)。

另一方面，Case1基础最终种群中4/12seed存在更多完整幅值结构、没有新增幅值事件的诊断候选；其中3个在MAG/PHA二维前沿外，另1个在前沿内但未被膝点选中。这支持继续研究整体分数与局部结构之间的偏好差异，不等同于候选所有局部量都更好。

### Root、差分B、JV：修复部分反例，尚未达到准入条件

|候选|固定旧24对排序方向一致数|结果|
|---|---:|---|
|原ARX|20/24|工作对照，自身仍有错误|
|Root|17/24|修复两个P3已知例，未通过原准入条件|
|复向量差分B|13/24|仍有缺失/快速变化反例；受控错位响应也可非单调|
|JV=(JM+JC)/2|19/24|两个P3例修复；已有失真仅5/8，且成本未通过|

这些样本已经参与研究，24对不是独立盲测，不能作为通用准确率。JV的756项评分任务数值检查通过，但未运行新优化；当前耗时比中位数6.46，高于1.25准入线。JM、JC、JV在36对样本上的方向完全相同，没有证明总量与累计分布的额外互补排序收益。见[几何后续结论](../output/geometry_followup_20261016/FINDINGS.md)、[JV正式报告](../output/variation_transport_20261017/REPORT.md)。

### 最新谷过程控制：得到诊断依据，尚未得到新优化目标

旧位置、高度和3dB宽度门槛可能允许整段复轨迹仍明显错误。266项物理扰动进一步证明：谷变窄时归一化变化分布可以不变；附加窄支路可能不增加峰谷数量；结构移出核心区后局部分数反而可能下降。

随后完成75项纯移频/边界控制和32个旧候选的归属记录。75项控制全部正确，但旧32项都无严格纯移频签名，这不代表32项都没有目标谷；一般形变归属仍未解决。

最新166项包括134项新控制、32个旧候选。49项已知几何恒等控制、134项独立节点响应核验均通过。Q变化可以保持有序复路径及路径量，却使频率宽度变为约0.303—3.333倍，支持把以下量分开保留：

- G：有序复状态差；
- P：去中心后的频率展开差；
- 路径量、中心频移、绝对半径宽度和额外极值序列。

固定半径截段可能包含多个谷、只截到局部或无法闭合。尚无一般形变的唯一归属与接受阈值，也未把G/P合成新目标或证明优化收益。详见[形态与展开控制报告](../output/valley_shape_20261017/REPORT.md)。

## 3. 下一步应沿哪条线继续

1. 先解决固定窗口/固定半径下无界段、缺失段和多谷的连续引导与归属歧义，保留所有反例。
2. 在旧固定反例和受控物理变化上，检查是否同时识别缺失、形变、位置偏移及额外过程；不能事后调阈值宣称通过。
3. 达到事先冻结的数值、排序及成本准入条件后，再冻结一项轻量候选，开展相同初始化、60000评价预算、统一MAG/PHA二维膝点的配对优化。
4. 同时比较普通复误差、匹配窗口权重、原ARX及适当参考；报告结构、两项主误差、额外事件和耗时，最后再做独立参数/电路、噪声和实测验证。

以上是待做研究，不是本次上传已经完成的工作。
