# 谷过程频率归属：保守实现与核验方案

日期：2026年10月17日。范围：本地过程记录与数值核验，不设计辅助目标、不优化、不改旧标签。

## 1. 区分两件事

**占位**：当前目标核心区里有几个严格径向谷。分别记录零运动、无谷、边界谷、单候选、多候选。这不等于完成目标过程。

**对应证据**：在更宽的搜索区列出全部谷候选，逐个比较平移后的复轨迹状态和导数签名；保存实际频率偏移，不将对齐结果冒充位置正确。没有严格一致证据时，明确记录可能变形或归属未确定，而不是强行匹配最近的一个谷。

当前只验证严格平移一致这一有限子问题，不声称自动判断任意形变后的物理模式身份。极值属于端口响应，不能直接认作某条支路的唯一谐振模态。

## 2. 固定方法

- 目标沿用前轮五个目标，核心区保持原边界。搜索区固定为目标精化谷中心左右各4个核心总宽度，候选不能改变搜索区。
- 模态锚点加128/256细分，必要时512/1024，解析径向速度零点连续求根。保留所有严格谷，不按峰高或新分数筛选。
- 数值位置保护为10^-9 decade：落在核心边界该距离内的根单列“边界”，不算严格区内或区外。该值用于数值归类，不是拟合合格容差。
- 签名采样使用目标核心左右边界相对谷中心的17个等距偏移及中心点。对每个候选谷，以同样频率偏移取Z和dZ/dlog10 f；阻抗除以目标中心幅值S，导数乘目标核心宽度再除以S。候选不得自行缩放。
- 对平移后状态及导数分别使用10^-8绝对、10^-7相对的原数值关系门槛。它只检查是否与目标采样签名数值一致，不作为允许形变的结构合格线。多候选一致则保留多义；零候选一致不等于谷一定不存在。
- 同时给出未对齐的频率偏差、候选谷处Re/Im、全部签名残差和核心占位；不把频率对齐用于优化或正式膝点选解。

## 3. 核验数据

新增75项已知整体移频检查：五目标各9档−1.75、−1.25、−0.75、−0.375、0、0.375、0.75、1.25、1.75核心宽度，共45项；再将谷放在每个核心边界的−5×10^-9、0、+5×10^-9 decade处，共30项。原值和部分精确边界与旧设置可能重合，不能称75个独立样本。

操作均通过所有L、C同时除以s实现。生成时保存已知谷频率，**归属程序不读取操作量或预期位置**；完成后才核对定位误差、签名一致与区内/边界/区外状态。全部参数先冻结。

再对上轮266个物理设置统一运行作回归检查。除原值和整体移频外，偏置、Q、附加支路等并不保证满足严格平移签名，不能把未通过当作匹配算法错误，更不能据此改签名容差。

最后检查旧32条混合候选，全部搜索V3，补充占位、对应证据及原状态/弧长记录。重点解释此前五对争议，保留旧好坏标签；不将新记录直接转成新完整率或新排名。

总计373项记录，包含重复参照、回归和相关扰动，不是独立统计验证。两个混合目标仍属开发，简单模型仍是机制参照。

## 4. 决策和限制

75项整体移频应找到唯一数值一致签名，位置误差≤10^-9 decade，并正确记录核心位置，包括边界。背景参照应不被强行分配成目标谷。所有根数、类型、签名结论及位置分类需要双细分稳定；失败原样保留，不放宽标准。

这最多确认数值匹配在已知平移子问题上的表现。旧候选的变形对应若仍未确定，应明确说明下一步需要独立的形变定义和容差，不把“未确定”写成真实缺失，也不以内部参数路径强行赋予可观测曲线身份。
