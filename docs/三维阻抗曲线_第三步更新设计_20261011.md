# 第三步更新：从困难结构到一个可检验的三维指标

2026年10月11日。结合Case1与7类新电路重新设计，随后开展小规模配对验证。本文先解释设计依据，实验结论单独记录，避免把想法与有效性证据混在一起。

**本轮结果已按膝点替换：** 32次原优化的完整种群重新选解，梯形重点结构0/4→3/4，混合支路3/4→2/4，Case1两组仍0/4，简单RLC保持4/4。统一结论见[新版通俗报告](../output/mse_structure_step3_knee_20261011/FINDINGS.md)。指标定义保持冻结；1条训练辅助分数偏差仍保留，旧选解报告已弃用。

## 1. 新结果改变了什么？

**我们需要同时考虑“极窄局部偏差在平均分中份额很小”和“局部已有较大误差贡献，仍难恢复”两种情形。** 新电路增强了后一种证据，所以不能再用一个“平均稀释”的理由解释全部困难。

|证据|说明了什么|没有说明什么|
|---|---|---|
|Case1原尖峰核心约13.3 Hz，1000代时平均局部幅值RMSE约38.7 dB，但幅值总误差贡献均值约0.85%|一个极窄的严重局部偏差，在全频平均分中可以份额很小|不能证明全部组合误差都被忽略|
|Case1把其他17个参数放在真值，只将R2减半：峰低约6 dB、宽度约两倍；六档目标越窄，整体MAG/PHA增量越小|直接评分已有“局部要求与平均分尺度不一致”的例子|没有让优化器搜索，不能推出越窄必然越难搜索|
|Case1的23—26 kHz组合窗口，在1000代平均占幅值总误差约23.4%、相位约41.1%|峰谷组合的持续失败还涉及搜索、参数联动或取舍|不支持“整个局部区域都被MSE忽略”|
|新梯形网络基准第二峰8次都有，7次高度不合格；峰核心平均占幅值总误差约24.9%|占较大误差贡献的次峰，也可能长期偏矮|不能只用增加局部权重解释成因|
|梯形网络倍率8的相邻谷峰各4/8漏失，末代仅1/8 seed有幅值结构全合格的候选|出现局部轨迹绕过、伸出不足与相位回转缩小的重复实例|尚未证明新增几何分数一定帮助找到正确参数|
|单并联RLC约83.1 Hz的窄峰8/8恢复；某些混合电路更宽的结构也会失败|绝对Hz宽度不能单独决定困难|不同中心频率、维数、背景与拓扑尚未受控|
|三级网络被判漏失的部分相位事件，只是很小的角度起伏|事件数量与实际失真严重程度需要分开|不能把所有相位事件都等权强化|

这些计数来自不同预算、边界和模型，分别提供证据，不合并成一个跨电路“总成功率”。Case1第一步100seed与第二步24次探索也不能当作独立重复样本直接相加。

资料：[Case1第二步报告](../output/mse_structure_step2_20261009/REPORT.md)、[新电路通俗结果](../output/mse_structure_complex_20261010_server/研究结果_通俗解读.md)。其中各百分比先对每条曲线计算，再取seed均值，不是把两列均值直接相除。

## 2. 现在针对的结构长什么样？

把频率、实部和虚部画成三维曲线，峰谷及相位联动可以表现为：轨迹在局部向外伸出、朝轴靠近、绕轴改变方向，再折回。

目前优先针对：**目标要求的一段局部轨迹，在拟合中被绕过、被缩小，或者频率展开和转向不对。** 它包含Case1极窄峰及邻谷，也包含梯形网络的次峰、谷峰组合，不把研究对象限定为“所有窄峰”。

一条拟合曲线有峰，不代表峰高、谷深、宽度和相位过程都正确；反过来，细小相位起伏没恢复，也不能直接认定为严重失真。

## 3. 三个原候选的优先级怎样调整？

|候选|更新判断|
|---|---|
|局部三维轨迹瓶颈误差|继续作为第一候选；峰谷分别归一化，检查顺序与频率位置，关注重点结构中较差的一项|
|三维切线走向误差|保留为第二候选；更适合结构已经出现、位置幅度较合理，但转向过程仍明显不对的情形；它单独保护不了峰高和谷深|
|多尺度转弯误差|暂缓作为第一轮目标；新结果提示小相位起伏也会生成速度/转弯事件，应先定义可靠性与实际意义，避免过度修复小细节|

“瓶颈”可以理解为：即使给两条曲线一个有限的、按频率顺序的对应机会，最难贴合的一处还差多少。它是一个几何要求，不是已经证明正确的搜索策略。

## 4. 第一候选现在怎样写得更具体？

每个重点峰、谷都先有目标确定的局部窗口。目标中心为u*，目标对数频率3 dB宽度为w*，u＝log10(f)。定义无量纲三维坐标：

\[
q(u)=\left(\frac{u-u^*}{w^*},\frac{\operatorname{Re}Z(u)}{S},\frac{\operatorname{Im}Z(u)}{S}\right).
\]

S来自目标在该窗口中的阻抗幅值；实部、虚部共用同一个S，目标和所有候选都用同一套尺度。不能将候选自己归一化到同样大小，否则“峰低一半”的错误可能被消掉。

窗口先取中心前后各3个目标宽度，再按相邻事件的中点裁剪。这样峰的窗口不会跨过谷中心，谷的窗口也不会吞入邻近大峰中心。仍可能受到邻近背景影响，且窗口范围不是已证明最优的常数。

对两条窗口曲线，按频率递增顺序匹配，覆盖两条完整离散序列的起点、终点与中间点。允许的对应频率偏移不超过0.25个目标宽度。计算所有允许对应方式中，最大三维连接距离的最小值，得到每个事件分数F。

顺序匹配与最大连接距离采用[离散Fréchet原始定义](https://www.kr.tuwien.ac.at/staff/eiter/et-archive/files/cdtr9464.pdf)的思路；局部窗口、归一化、频率偏移限制和事件聚合是本轮针对阻抗的设计约定，不是该文献已验证的阻抗优化方法。

峰、谷两个分数最后取最大值，作为一个第三目标：

\[
E_{\mathrm{geom}}=\max\{F_{\mathrm{peak}},F_{\mathrm{valley}}\}.
\]

简单对照只有一个峰，就使用该峰分数。MAG/PHA仍然是两个独立基础目标，不预先设置几何项与幅相项的加权总分。

### 为什么这次不把峰谷放在同一个大Ω尺度下？

Case1峰顶约3000 Ω，谷附近小得多。一个大窗口使用峰的尺度，可能让谷和低阻抗处的相位错误获得很小的几何偏差。分开尺度后，峰和谷各自按自己的局部范围评分。

这也有代价：小阻抗窗口可能变得很敏感，需要保留基础PHA，进一步检查噪声、尺度与实际重要性。分区不等于解决了低幅值相位问题。

### 为什么先把两个结构取较大值？

希望两个重点结构中较差的那一个不要又被另一个的好分数冲淡。但最大值在优化时也可能使另一项暂时没有选拔作用，或过度强调很小的窗口。因此它只是本轮冻结的设计选择，实验后必须检查是否发生这种现象；不能看到效果不好就临时改成平均再算同一次试验。

### 它和以前的平均距离有什么不同？

此前同频点的频率坐标相同，频率残差为零，本质上是复平面上的平均欧姆误差。这次明确利用频率顺序、有限错位、局部尺度和最大偏离。

实部、虚部仍来自原始复阻抗，只做固定的正尺度归一化；不使用20log|Z|作为复平面的半径。

## 5. 这个版本仍没有覆盖什么？

两个分区窗口各自约束顺序，但两个窗口之间的连接段没有直接进入几何目标。频率顺序和局部形状比较更明确了，**仍不能把几何分数低写成整个峰谷组合三维轨迹完全正确**。本轮会另外检查包含连接段的局部相位误差。

训练评分使用固定的129点局部网格及强制事件中心。这是离散分数，候选仍可能在两点之间产生尖锐细节。因此优化后要用更密网格、候选模态位置独立复核。若发现遗漏，应把它作为此实现的失败边界，不能因为公式讲得合理就宣布有效。

只有目标被可靠记录的结构，才适合给出精确窗口、宽度和尺度。理论电路可以加密检查；实测数据中未分辨的峰不能凭插值编出真实形状。Case2本轮不用于无噪声几何验证。

## 6. 这一轮怎样区分“搜索改善”和“换取舍”？

最终代表统一改为末代MAG/PHA二维前沿的膝点；没有可辨识凸膝点时使用冻结的退化折中，逐seed标明。辅助组同样使用二维投影前沿，辅助分数不参与挑最终曲线。具体算法见[新版选解约定](../experiments/mse_structure_step3_knee_20261011/PROTOCOL.md)。

每seed只报告一个最终代表；不再保留加权最小或有限取舍代表结果。结构恢复、两项全频误差和其他结构的代价分别检查，膝点不自动保证幅相可接受。

后一种改善不能冒充前一种改善。也不能仅凭第三目标下降下结论，需要独立检查峰谷位置、高度、宽度、局部相位、其他结构和计算成本。

本轮使用Case1、两种复杂电路条件和简单对照，各4个配对新seed、每组300代。它是第一个探索验证，不是最终推广证明。已被用来提出这些设计的电路，不能再称为独立未见的验证数据。

原优化冻结设置见[原始protocol.json](../experiments/mse_structure_step3_20261011/protocol.json)，其中历史选解字段已停用；新版选解约定和结果见[第三步统一报告](../output/mse_structure_step3_knee_20261011/REPORT.md)。

## 7. 四个问题仍是结论的顺序

1. **哪类结构反复困难？** 已从泛泛的局部失真收拢到峰高不足、谷峰联动和局部三维伸出/回转缺失。
2. **什么条件使它更难？** 极窄峰的评分份额有直接证据；更广泛的参数联动、相邻结构和搜索困难仍是未分离的因素。
3. **指标能否改善？** 用本轮配对试验回答，允许无效或仅改变取舍，不由设计解释预先决定。
4. **能否推广，成本怎样？** 先检查开发样本与成功对照；后续还需未参与开发的新参数、电路、seed和真实数据，以及采样与计算成本验证。
