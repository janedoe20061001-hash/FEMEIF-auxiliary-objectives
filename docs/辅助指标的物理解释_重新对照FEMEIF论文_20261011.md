# 重新看FEMEIF：辅助指标应该帮助电路恢复什么？

2026年10月11日。本次核对论文、已有指标和已完成实验，整理设计方向；没有启动新优化实验，没有上传网站。

后续更新：用户继续授权讨论与实验后，已完成本地物理状态诊断。见[通俗实验报告](../output/physical_state_diagnosis_20261011/REPORT.md)。它说明本稿三个过零特征的覆盖限制，并补充了非零相位极值、额外容性起伏与整体阻抗尺度的证据；尚未验证新辅助目标的优化增益。下文保留最初提出这些物理猜想时的推导和边界。

**这次批评有依据。前一轮比较清楚地描述了“曲线哪里不像”，但还没有充分解释“它对应电路中的什么状态，以及为什么单独奖励这个状态有助于搜索”。这是指标设计的一项实质缺口，不能靠给原来的公式换一个物理名称补上。**

不过，物理解释和优化有效是两回事。一个指标能够解释谐振，并不自动保证它能改善拟合；一个几何指标暂时有效，也不等于它已经找到了电路机理。两方面的证据都需要。

## 1. 论文中的PTC，为什么比较有说服力？

先把阻抗理解成电路对交流电的“阻碍方式”。交流电频率改变时，电感和电容的作用也会改变。在某些频率附近，它们相互抵消或使端口表现出很强的阻抗变化，曲线上便可能出现峰和谷。

FEMEIF论文第3页C节，将幅值峰谷联系到电感、电容形成的谐振，并用峰谷位置指导参数调整。PTC的检查比“附近有没有峰谷”更具体：

1. 按目标峰谷划分邻域。
2. 在对应邻域内，比较候选曲线的同类事件：峰对峰、谷对谷。
3. 对同类事件的频率偏差计分；论文的特征计算采用对数频率坐标。
4. 缺少同类事件时加缺失惩罚。同一区域内多个同类事件的偏差累加。

论文没有直接对该区域内的反类事件加罚，目的是避免反而偏爱峰谷很少的候选。因此，PTC本身也不是完整的“所有多余结构检查器”。它还不直接检查峰高、谷深和宽度。

它的说服力来自一条比较清楚的联系：

> 峰谷的频率位置与谐振有关 → 位置较接近的候选值得保留 → 即使当前整体误差还较大，也可能继续调整参数得到好结果。

论文第5页总结了更一般的设计意图：辅助目标帮助保留那些当前误差不突出、但可能通过较少调参继续改善的候选。**辅助指标不只是另一把衡量“像不像”的尺子，还应该解释为什么这个候选值得继续搜索。**

“先把谐振基本调正确”很好地概括了这种意图。但论文使用的是主目标与辅助目标共同参与的多目标优化，不是先完成PTC、再开启误差优化的两个独立阶段。

也需要保留一个限制：峰谷位置接近，不能证明每个电感、电容都正确。例如简单RLC的谐振频率由LC的乘积决定，许多不同的L、C组合可以有相同频率。论文的物理解释是筛选候选的依据，并不是参数唯一识别的证明。

## 2. 电抗过零，又检查了什么？

写成：

\[
Z(f)=R(f)+jX(f).
\]

R是阻抗的实部，X是虚部，也叫电抗。在通常约定下，X为负表示端口偏容性，X为正表示偏感性。

当X＝0且R＞0时，端口电压和电流同相，输入阻抗呈纯阻性。可以理解成：**从外部端口看，这个频率下的感性作用与容性作用达到了平衡。** 这不代表电路内部没有电感、电容，也不代表内部各支路都没有无功交换。

已有I-03检查的是：目标过零事件所在区域内，候选是否也有同方向的过零。方向区分“容性变感性”和“感性变容性”。我核对了当前代码，它并没有直接精确比较过零频率，也没有检查过零附近的变化陡峭程度。因此，把这些原有检查重新命名，不能算新指标。

还有一个容易混淆的地方：**复杂电路的幅值峰谷不一定正好位于X＝0。** 实部也可能随频率变化，多个支路还会相互影响。因此，峰谷检查和过零检查各有职责，不能强行把每一个峰、谷与过零点配成一对。

## 3. 回看这轮指标，缺口具体在哪里？

|当前指标|确实检查了什么|物理解释还缺什么|
|---|---|---|
|R：径向极值|峰高、谷深是否接近|某些简单电路中可联系到电阻或损耗；复杂电路中，峰高不直接等于某个元件的电阻|
|F：沿频率的占据分布|出现位置、展开范围和两侧分布|可能对宽度有帮助，但目前的累计分布不是直接的品质因数或阻尼指标|
|T：角度进程|相位怎样转向、转了多少、在哪段转|有容性与感性转换的解释潜力，但宽区间的累计转角尚未对应到明确的局部谐振状态|
|C、B：顺序轨迹与连接|指定区间内的三维路线是否接近|主要是几何贴合；尚未说明它优先保留了哪一类容易继续调好的电路状态|
|X：多余往返|局部有无多余起伏或折回|错误的平滑曲线也可能得低分，单独使用不能引导恢复谐振|

已有膝点版实验中，T、C、B在部分电路有改善，同时存在失败和副作用。这些是有价值的经验线索，**还不是“已经建立了物理机制”的证据**。当前实验结果仍按[已完成的报告](../output/mse_structure_step3_knee_20261011/FINDINGS.md)解释，不因这次重新讨论而改变数据或结论。

也不必把所有几何指标都否定。论文自己还用了形状相似度和动态时间规整等特征。更合理的要求是：每个候选必须说清楚自己检查什么、为什么可能帮助搜索，以及这个解释在哪些电路中成立。

## 4. 一个简单例子：谐振位置正确，为什么还不够？

考虑R、L、C串联。电阻耗能，电感和电容储能。谐振频率f₀与品质因数Q满足：

\[
f_0=\frac{1}{2\pi\sqrt{LC}},\qquad
Q=\frac{1}{R}\sqrt{\frac{L}{C}}.
\]

Q可以在这个简单电路中理解为谐振的尖锐程度：Q越高，变化越集中在谐振附近。串联RLC在谐振处出现阻抗谷，而不是阻抗峰。这里所说的带宽，是阻抗从谷底升高3 dB的两侧频率之差，不是从峰顶降低3 dB。简单RLC的谐振、Q和带宽关系可参见[MIT的RLC讲义](https://web.mit.edu/6.101/www/s2019/handouts/L02_4.pdf)。

下面只是公式算例，没有运行新的拟合实验：

|参数或特征|电路A|电路B|
|---|---:|---:|
|R|10 Ω|10 Ω|
|L|1 mH|4 mH|
|C|100 nF|25 nF|
|谐振频率|约15.9 kHz|约15.9 kHz|
|谐振处阻抗|10 Ω|10 Ω|
|Q|10|40|
|上述带宽|约1592 Hz|约398 Hz|

两个电路的LC乘积相同，所以谐振频率相同；谷底阻抗也相同。但是，电路B的谷明显更窄。

这说明：**位置、阻性水平、转变的陡峭程度是不同的信息。** 只把位置对齐，或者只把谷深调对，仍可能留下重要结构偏差。这个例子也说明，改变L、C不只会移动谐振频率；保持乘积不变地改变它们，仍会改变Q。

## 5. 更值得沿着物理现象设计的一组特征

仍然从原始三维曲线提取信息：

\[
\bigl(\ln f,\ \operatorname{Re}Z,\ \operatorname{Im}Z\bigr).
\]

使用对数频率只是方便观察多个数量级；实部、虚部仍是原始阻抗。指标不必都是三坐标的欧氏距离，也可以检查这条线经过什么状态、在哪里经过、如何经过。

### 第一类：事件的类型与位置——谐振结构有没有对上？

幅值峰谷用PTC作已有参考，过零方向用I-03作已有参考。缺失、方向错误和位置偏差分别记录，避免压成一个分数后不知道哪里错了。

可能的扩展是让过零检查也区分“存在但明显错位”与“完全缺失”，而不只是同一区域有过零就算匹配。这需要与I-03直接比较，不能当作已证明有效的新发现。

### 第二类：过零附近的角度变化速度——谐振的尖锐程度有没有对上？

一条线由容性一侧穿到感性一侧，可以穿得很快，也可以缓慢过渡。前者在相位图上转向更陡。这个特征有机会解释此前“幅值大致正确、局部相位转换仍错误”的现象，但尚未证明它就是那些失败的原因。

在可靠的X＝0、R＞0处，取u＝ln f、相位φ，则有：

\[
\left.\frac{d\phi}{du}\right|_{X=0}
=\frac{1}{R}\frac{dX}{du}.
\]

这是从原始实部、虚部曲线得到的局部关系。对简单串联RLC，该值为＋2Q；对理想的R、L、C三支路并联RLC，该值为−2Q。因此，可以把过零处的方向和角度陡峭程度一起比较。

这些简单电路中的Q关系，也可由上述[MIT讲义](https://web.mit.edu/6.101/www/s2019/handouts/L02_4.pdf)给出的阻抗与Q公式推导得到。这里的角度导数推导列在文末。

**在嵌套电路中，先称它为“端口转变陡峭程度”，不能直接称为某个内部谐振模式的Q。** 相邻谐振、背景支路和频率相关损耗都可能影响它。目标过零必须可靠，低阻抗、噪声很大、过零不孤立时不能机械取导数。

这比给原来的T加上“谐振指标”名称更严格：它规定了要观察的局部状态，也说明了在什么条件下能联系到阻尼或Q。不过，它与已有局部导数指标可能重叠，新颖性和额外搜索价值仍需要检查。

### 第三类：过零时的实部——阻性状态的水平有没有对上？

同样呈阻性，10 Ω与100 Ω仍是完全不同的电路响应。在固定端口电流下，实部决定输入有功功率：P＝I²R，这里的I是有效值。

因此可以比较对应过零事件处的实部。它回答的是“端口呈阻性时阻抗有多大”，与第二类的转变速度分开。

在上述简单串联或并联RLC中，谐振处实部等于电阻R；在复杂电路中，它是整个网络形成的端口等效水平，不能直接归因于某一个电阻，更不能把它单独称为全部损耗或阻尼。

三类特征合起来，在简单RLC中分别联系到谐振位置、尖锐程度和阻性水平。它们不是三项新的独立物理量，而是把同一条阻抗曲线中有解释的状态单独提出来。

## 6. 物理故事还需要过哪些检查？

正式设计优化指标之前，每个候选至少应回答：

1. **它检查什么状态？** 是输入端的谐振位置、容感转换、转变速度，还是别的现象？
2. **在哪些条件下成立？** 简单RLC中的推导能否适用于当前嵌套电路？哪些峰谷与过零不能配对？
3. **为什么能帮助搜索？** 能否保留一些MAG/PHA暂时不突出、但关键状态已接近目标的候选？还是仅把原来的误差重复算一遍？
4. **怎样防止错误的低分？** 例如纯电阻处处X＝0，却没有目标需要的容感转换；事件漂出区域、出现额外事件，也不能免费通过。

目标事件、检查区域、尺度和可靠性必须事先固定。不允许把候选自行旋转、平移或缩放后再匹配，也不能让候选把评分区域搬到自己更好看的位置。实测数据中没有可靠记录的尖峰，不能靠这些指标推断成已观测事实。

设计上还要区分“检查用的特征”和“用于优化的分数”。事件缺失时如何给惩罚、如何提供连续变化的引导、各事件怎样合并，都尚未冻结。现在不能把上面三个方向当作可以直接开跑的完整指标。

后续仍围绕四个问题：哪类结构反复难恢复、什么条件使它更难、针对指标是否改善、能否推广及代价是什么。MAG/PHA保持基础目标，最终代表仍遵守当前统一膝点规则；选解的局限另外检查。PTC和I-03应作为已有特征参考，避免把成熟思路重新包装成新发现。

## 7. 本次讨论改变了什么？

新增的设计要求是：在定义分数之前，先解释要恢复的电路状态，再说明这种检查为什么可能帮助搜索。已有的几何方案保留其真实证据，但不再把它们当作物理解释已经完整的方案。

接下来更值得做的是，用已有曲线检查上述状态：失败曲线究竟是事件位置没有对上、阻性水平不对，还是转变速度不对？如果简单电路中的解释在嵌套电路里不成立，就修正或舍弃该解释，再决定哪些候选值得进入优化实验。

本次没有证明新特征有效，也没有证明MAG/PHA理论上无法拟合这些结构。它完成的是对论文设计思路的重新核对，以及下一轮指标需要补足的解释框架。

## 附录：为什么过零处的角度变化速度能联系到Q？

对一般可微阻抗Z＝R＋jX：

\[
\frac{d\phi}{du}
=\frac{R\,dX/du-X\,dR/du}{R^2+X^2}.
\]

在X＝0且R＞0时，上式变成(dX/du)/R。对于串联RLC，X＝ωL−1/(ωC)，在ω₀²LC＝1处：

\[
\frac{dX}{d\ln\omega}=2\omega_0L,
\qquad \frac{d\phi}{d\ln f}=2\frac{\omega_0L}{R}=2Q.
\]

对于三支路并联RLC，导纳Y＝1/R＋j(ωC−1/(ωL))，阻抗相位是导纳相位的相反数，因此谐振处角度导数为−2ω₀CR＝−2Q。导数使用弧度；换成log₁₀ f时还需乘ln 10，不能混用。

幅值峰谷与过零也可以从公式区分。因为|Z|²＝R²＋X²：

\[
\frac{d|Z|^2}{du}=2\left(R\frac{dR}{du}+X\frac{dX}{du}\right).
\]

X＝0时，如果R仍在随频率变化，上式未必为零，因而该点未必是幅值极值。这正是复杂网络不能机械把峰谷与电抗过零等同的原因之一。
