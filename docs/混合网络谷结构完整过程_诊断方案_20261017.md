# 混合网络谷结构：完整复轨迹过程的诊断方案

日期：2026年10月17日。范围：本地分析已有参数与理论响应，不运行优化，不改既有指标、标签、阈值或失败结论。

## 问题

旧规则的完整事件只约束谷的位置、幅值及3 dB宽度。本轮要明确：它是否遗漏了谷周围的复阻抗状态、沿频率的进入/离开过程和窄的附加往返。不能预设所有谷都必须形成圆环，也不能把幅值谷直接解释为端口电抗过零。

## 固定样本与坐标

使用上轮冻结24对库中两个混合网络条件的全部16对、32条候选。无论原配对针对P2、V1、V3还是间隙，本轮都检查其V3。五个已知失败对用于详细展示，其余样本保留，避免只挑反例。两个真实目标作为参照。这是开发诊断，不是新验证集。

固定两种频率范围：原V3目标窗口，以及目标V3的左/右3 dB交点之间的核心区。候选沿相同绝对频率取样，不平移频率、不按候选自身宽度归一化。固定目标阻抗尺度，候选不能自己缩放。

## 诊断内容

1. **端口状态**：在目标左交点、谷中心、右交点分别记录ReZ、ImZ及误差。保留候选自己的谷中心，单独记录错位，不能对齐后隐藏位置误差。
2. **谷的进入与离开**：设x=log10 f，v=dZ/dx。记录径向速度Re(conj(Z)v)/|Z|和切向速度Im(conj(Z)v)/|Z|。幅值谷对应径向速度由负变正；不要求ImZ=0。记录RR'与XX'的平衡及根的稳定性。
3. **过程持续的频率范围**：沿复轨迹弧长定义累计比例，记录10%、50%、90%位置及中间80%弧长所占频率宽度。它衡量轨迹运动集中在哪些频率，不等于3 dB幅值宽度，也不是电路能量。
4. **是否出现附加往返**：记录区间内径向极值的类型与顺序、总弧长、端点位移和位移/弧长比。以目标实际过程为参照，不能把“有环”或“无环”直接判好坏。
5. **旧宽度是否掩盖不对称**：对已匹配谷补算1 dB与3 dB绝对高度交点，分开记录左右距离和不对称程度。此项用于解释旧标签，不作为新的幅相辅助指标。

合成物理参照使用串联RLC：其谷中心电抗过零，Re/Im轨迹是直线；与混合网络V3对照，说明不能统一要求圆环或纯阻性状态。串联RLC公式与径向/切向分解均直接代数核对，不据此推断复杂网络内部唯一谐振模式。

## 数值与解释约束

采用目标与候选模态锚点的128、256细分并比较连续量、根数与根位置；弧长另用解析导数Gauss积分复核。候选端口响应抽样与独立节点解比较。失败和未匹配保留，不强行给出谷宽。

本轮只形成连续诊断与可操作的检查框架，不根据32条旧候选选择新的通过阈值，不将诊断量合成为新评分。结论必须区分：旧事件达标、轨迹状态接近、运动过程接近、附加结构少；任何一项不能替代其余项。下一阶段若要设新判据，应另行冻结并用未用于当前分析的参数检验。

预定产出：完整32候选表、两个目标的端口状态与运动过程、代表三维/二维/速度图、旧宽度和弧长宽度对照、数值复核、正式报告及后续判据建议。无需连接服务器。
